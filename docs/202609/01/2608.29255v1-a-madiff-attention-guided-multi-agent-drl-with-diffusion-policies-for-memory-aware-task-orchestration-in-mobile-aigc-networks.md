## 摘要
人工智能生成内容（AIGC）服务利用生成式AI（GenAI）模型自动生成多样化内容。移动AIGC网络将GenAI模型部署在边缘位置的AIGC服务提供商（ASP）上，以便为移动用户提供低延迟和个性化的AIGC服务。然而，AIGC推理任务通常在完成之前一直占用GPU内存，导致服务ASP的GPU内存耗尽，并引发内存溢出故障，而不仅仅是增加服务延迟。现有关于AIGC任务编排的研究在很大程度上忽略了GPU内存可行性约束。为解决这一问题，我们开发了一种协作式多智能体编排框架，其中每个边缘节点配备一个调度智能体，将任务路由到本地ASP或相邻边缘节点。由于调度智能体仅基于局部观测做出决策，而对等卸载会耦合其资源状态和长期效用，我们将编排过程建模为协作式去中心化部分可观测马尔可夫决策过程（Dec-POMDP）。为求解该Dec-POMDP，我们提出了一种基于注意力引导的多智能体深度强化学习算法，采用扩散策略（A-MADiff），并采用集中训练与去中心化执行范式。A-MADiff利用基于扩散的去中心化actor在可行的编排动作上生成多模态偏好，并利用注意力引导的集中式critic在GPU内存异构性下从跨智能体状态估计每个智能体的价值。数值结果表明，A-MADiff显著提高了相较于最先进基线的累积奖励。

## Abstract
Artificial Intelligence-Generated Content (AIGC) services employ Generative AI (GenAI) models to automatically generate diverse content. Mobile AIGC networks host GenAI models on edge-located AIGC Service Providers (ASPs) to deliver low-latency and personalized AIGC services for mobile users. However, AIGC inference tasks typically occupy GPU memory until task completion, causing GPU memory exhaustion at serving ASPs and triggering out-of-memory failures rather than merely increasing service latency. Existing studies on AIGC task orchestration have largely overlooked GPU memory feasibility constraints. To address this issue, we develop a cooperative multi-agent orchestration framework, in which each edge node is equipped with a scheduling agent to route tasks to local ASPs or neighboring edge nodes. Since scheduling agents make decisions based only on local observations, while peer offloading couples their resource states and long-term utilities, we formulate the orchestration process as a cooperative Decentralized Partially Observable Markov Decision Process (Dec-POMDP). To solve the Dec-POMDP, we propose an \underline{A}ttention-guided \underline{M}ulti-\underline{A}gent deep reinforcement learning algorithm with \underline{Diff}usion policies (A-MADiff) under the centralized training with a decentralized execution paradigm. A-MADiff employs diffusion-based decentralized actors to generate multi-modal preferences over feasible orchestration actions, and an attention-guided centralized critic to estimate per-agent values from cross-agent states under GPU memory heterogeneity. Numerical results demonstrate that A-MADiff significantly improves the cumulative reward over the state-of-the-art baseline.

## 1. 论文的核心问题与整体含义（研究动机和背景）

- **背景**：AIGC服务通过生成式AI（GenAI）模型在移动网络中提供低延迟、个性化的内容生成服务（如文本、图像、视频）。由于移动设备无法承受GenAI推理的计算和内存开销，移动AIGC网络将GenAI模型部署在边缘位置的AIGC服务提供商（ASP）上。现有研究多从ASP选择、服务编排、计算卸载等角度优化AIGC服务，但大多只关注计算资源、带宽、缓存等软性资源，**忽略了GPU内存作为硬性约束的作用**。
- **核心问题**：AIGC推理任务在GPU上执行期间，模型权重、KV缓存和中间激活需持续驻留GPU内存直至任务完成。当运行时GPU内存不足时，任务会发生OOM（Out-of-Memory）失败，无法执行——这与计算能力不足仅导致延迟增加有本质区别。GPU内存可行性是任务能否执行的**硬性条件**，而非软性性能代价。在分布式移动AIGC网络中，请求动态到达各个边缘节点，各节点的ASP在推理速率、服务能力和GPU内存容量上均异构，任务编排需要多个分布式调度智能体协作完成，形成长期耦合的决策过程。现有以单一调度实体为核心的ASP选择或服务编排方法无法刻画这种分布式交互。
- **整体意义**：本文首次将GPU内存可行性约束系统性地引入AIGC任务编排层，建立了协同多智能体编排框架，将问题形式化为合作式Dec-POMDP，并提出了A-MADiff算法求解，填补了内存约束下多智能体AIGC任务编排研究的空白。

## 2. 论文提出的方法论

- **系统建模**：
  - **框架结构与动作空间**：每个边缘节点部署一个调度智能体，可对当前任务选择三类动作：本地执行（分配给本地ASP）、对等卸载（迁移到相邻节点）、排队延迟（放入本地等待队列）。动作空间为 `A_n = {a_loc} ∪ {a_n' | n'∈N_n} ∪ {a_def}`。具体ASP选择由执行层准入与放置规则完成，避免动作空间随ASP数量膨胀。
  - **GPU内存约束建模**：定义物理容量可行集 `K_cap_n(i) = {k∈K_n | M_cap_n,k ≥ m_i}` 和运行时可行集 `K_run_n(i,t) = {k∈K_n | M_av_n,k(t) ≥ m_i}`。结构可行动作集F_t_n用于排除物理容量、跳数、队列容量层面的不可行动作；而运行时可用GPU内存不预先过滤本地执行动作，若选择本地执行但运行时内存不足，则触发OOM失败并获得失败惩罚`R_fail`，从而保证GPU内存作为硬约束在调度层生效的同时不赋予策略对逐ASP内存状态的完美知识。
  - **Dec-POMDP形式化**：状态S_t包含当前任务、等待队列、ASP资源（推理速率、GPU内存状态、运行任务集）、链路状态和随机状态；局部观测o_t_n由任务特征、本地状态摘要（计算负载、可用内存比、队列长度归一化）、邻居状态摘要组成。奖励函数区分本地执行奖励（按运行时可行集中最大化效用-延迟权衡的ASP）、对等卸载奖励（基于目标节点摘要的估计路由效用，扣通信与后续处理成本）、排队延迟成本`R_def`和失败惩罚`R_fail`。合作目标为最大化所有智能体奖励之和的期望折扣回报。

- **A-MADiff算法**（CTDE范式）：
  - **扩散策略actor**：每个智能体的策略为条件扩散模型。从高斯噪声`x_t_n,T_d`出发，经T_d步反向去噪（噪声预测网络ε_θ以局部观测、噪声向量和扩散时间步为条件），迭代得到动作偏好向量`z_t_n = x_t_n,0`，再通过掩码softmax在结构可行动作集F_t_n上规范化得到动作分布。多步迭代去噪使actor能够表达状态依赖的多模态动作偏好，优于单遍高斯/类别输出的MLP策略。actor通过SAC风格的熵正则化策略梯度端到端更新。
  - **注意力引导的集中式critic**：训练时，critic以所有智能体的联合局部观测为输入，先经共享观测编码器提取特征，再经多头自注意力（MHA）建模跨智能体状态交互，将每个智能体的编码与注意力上下文、one-hot智能体ID拼接后，由per-agent价值头输出该智能体在所有候选动作上的Q值向量。该设计自适应地对相邻节点状态加权——可用GPU内存大、队列短、延迟低的邻居获得更高注意力权重，避免均匀聚合带来的价值估计失真。采用双critic结构缓解Q值过估计，TD目标采用per-agent奖励分解与软状态值。
  - **训练与执行**：所有智能体共享一套actor参数，但在执行时依据各自局部观测和结构可行动作集做出不同决策。训练时critic利用联合观测提供集中价值指导；执行时仅需扩散actor推理，在线复杂度为`O(N·T_d·d_h² + N·T_d·A·d_h)`，不依赖critic。

## 6. 论文的主要结论与发现

- A-MADiff在累积奖励上比最优基线（MADiff）提升29.4%，比MASAC提升38.1%。
- A-MADiff取得最高的有效成功率（98.15%）和每任务平均奖励（0.6232），同时达到最低的负完成率（1.77%）和最低的OOM率（1.01%）。

- 注意力critic的效果：MADiff→A-MADiff的对比表明，注意力引导的集中式critic通过选择性聚合跨节点状态，帮助actor区分哪些邻居的内存与负载条件对当前卸载决策最相关，是性能增益的重要组成部分。
- 收敛与效率：A-MADiff收敛到更高的奖励平台且训练稳定，并以最少环境步数（7.2k）达到Greedy基线水平，比MADiff减少21.7%的所需步数。
- 鲁棒性：A-MADiff在GPU内存容量缩减、内存需求放大和任务到达率变化三种压力维度下均保持最高累积奖励，退化最平缓。

## 7. 优点

- **问题建模新颖且务实**：将GPU内存可行性作为硬约束与计算资源的软约束明确区分，并设计了"结构掩码（物理容量/跳数/队列）+运行时准入（可用内存）+失败惩罚"三阶段的内存感知机制，在保持约束硬性的同时避免给策略提供完美的逐ASP内存信息。
- **算法设计有机结合**：扩散actor与注意力critic分别针对多智能体决策中的两个核心困难——多模态动作偏好表达与异构跨智能体价值估计。per-agent边际critic设计避免了联合动作空间维度爆炸，同时通过注意力保留跨智能体耦合。
- **CTDE范式落地清晰**：训练集中、执行分散的边界清晰，在线推理仅需扩散actor，复杂度可控，工程可行性较高。
- **实验分析全面深入**：包含可解释性分析（扩散去噪过程可视化、注意力权重可视化）、鲁棒性三维度分析、消融对比（MADiff隔离注意力critic贡献），实验设计严谨、公平性好。
- **卸载与延迟策略的洞察**：动作组成分析揭示了更优策略倾向于主动对等卸载以缓解本地内存压力，并保留小幅defer比例以实现调度缓冲，提供了有意义的策略行为洞察。

## 8. 不足与局限

- **仿真环境与真实系统差距**：实验基于仿真环境，尚未在物理边缘测试台上验证（作者在结论中也承认这一点）。真实的GPU内存管理涉及内存碎片、KV缓存动态分配、显存分配器的具体行为等，论文的内存建模进行了较大简化。
- **模型假设的简化**：任务到达率设定为泊松过程，带宽固定、链路延迟均匀分布，没有考虑无线信道变化、用户移动性对任务到达的具体影响等复杂因素。此外，判定"完成"仅以ASP执行为准，未建模执行失败重试等其他终止路径。
- **扩展性未充分验证**：注意力机制的计算复杂度为O(N²)，论文仅在N=20规模下验证，更大规模的网络（如N=50/100）下注意力critic的训练效率和收敛性未做测试。
- **与其他最新方法的对比有限**：没有与更多专门面向AIGC编排的扩散DRL方法（如attention-diffusion DRL、EAT等）以及更专门的调度启发式算法进行对比。MADiff作为消融变体虽隔离了注意力critic的贡献，但没有独立的专门基线方法对照。
- **假设共享actor参数的合理性**：所有智能体共享同一组actor参数，依赖局部观测和各异的结构可行集来区分行为。在边缘节点异构性极强的场景下（如不同节点管理的ASP数量差异很大），共享参数的表达力是否受限未充分讨论。
- **奖励设计的领域依赖**：服务效用函数采用human-aware建模，但训练中G(·)的具体形式未展开说明，且效用评估依赖于主观的用户感知模型，可能在不同内容类型或用户群体间存在偏差风险。
