## 摘要
大型语言模型智能体越来越多地通过多智能体框架来解决长时程任务，其中中央智能体协调专门的子智能体、工具和环境。在此类框架中训练中央策略面临两个挑战。首先，动作标签是一个低基数的决策，而其参数构成高维条件序列；使用共享的序列级信号优化两者可能产生冲突梯度。其次，动态调度会创建具有分支、并行调用和上下文重写的相互依赖的会话，这些无法忠实简化为单一的扁平标记序列。我们提出了Harness-RL，一种结构化强化学习框架，将冲突感知策略优化（CAPO）与接口级黑盒轨迹构建相结合。黑盒组件捕获接口调用记录，构建每会话前缀树，并将结果和过程奖励与可训练标记对齐。CAPO利用前向激活来识别与动作和参数标记相关的参数分区，然后将其策略梯度路由到相应的子空间。Harness-RL支持仅中央训练和联合多智能体训练。在七个多跳问答和智能体检索基准测试中，使用Qwen2.5-1.5B和Qwen2.5-3B分别达到42.93和47.79的平均F1分数，而消融实验验证了CAPO的贡献，并在所评估的设置中倾向于仅中央优化。我们的代码可在https://github.com/jiangxinke/Harness-RL获取。

## Abstract
Large language model agents increasingly solve long-horizon tasks through multi-agent harnesses in which a central agent coordinates specialized sub-agents, tools, and environments. Training the central policy in such a harness raises two challenges. First, an action label is a low-cardinality decision, whereas its args form a high-dimensional conditional sequence; optimizing both with a shared sequence-level signal can produce conflicting gradients. Second, dynamic scheduling creates interdependent sessions with branches, parallel calls, and rewritten contexts, which cannot be faithfully reduced to one flat token sequence. We introduce Harness-RL, a structured reinforcement learning framework that combines Conflict-Aware Policy Optimization (CAPO) with interface-level black-box trajectory construction. The black-box component captures Interface Call Records, builds per-session prefix trees, and aligns outcome and process rewards with trainable tokens. CAPO uses forward activations to identify parameter partitions associated with action and args tokens, then routes their policy gradients to the corresponding subspaces. Harness-RL supports both central-only and joint multi-agent training. Across seven multi-hop question answering and agentic retrieval benchmarks, it reaches average F1 scores of 42.93 and 47.79 with Qwen2.5-1.5B and Qwen2.5-3B, respectively, while ablations validate the contribution of CAPO and favor central-only optimization in the evaluated setting. Our code is available at https://github.com/jiangxinke/Harness-RL.

## 2. 论文提出的方法论

### 核心思想
HARNESS-RL 框架由两个协同组件构成：**冲突感知策略优化（CAPO）** 与 **接口级黑盒 RL 机制**。黑盒机制负责将 Harness 交互转换为与 token 对齐的训练数据，CAPO 则将 Action 与 Args token 产生的梯度路由至各自的功能参数子空间。

### 关键技术细节

**（1）冲突感知策略优化（CAPO）——三步流程**

- **高质量轨迹构建**：对每个训练查询采样多个 rollout，保留成功的轨迹作为探测集（probing set），以降低失败行为激活模式带来的污染。
- **激活统计与功能划分**：
  - 利用前向传播中 Action token 和 Args token 在各层、各结构单元上的激活强度，分别计算决策特定的重要性分数：
    - $I_{action}(l,j) = \frac{1}{N}\sum_n \frac{1}{|I_{action}^{(n)}|}\sum_{t\in I_{action}^{(n)}} \phi(h_{l,j,t}^{(n)})$
    - $I_{args}(l,j) = \frac{1}{N}\sum_n \frac{1}{|I_{args}^{(n)}|}\sum_{t\in I_{args}^{(n)}} \phi(h_{l,j,t}^{(n)})$
  - 通过 TopK 选择各自最响应的结构单元，构成 Action 分区 $U_{action}$ 与 Args 分区 $U_{args}$。
- **Token 级梯度路由**：
  - 对于 Action 和 Args 各自的 token 位置集合 $I_{action}^{(r)}$ 与 $I_{args}^{(r)}$，将策略梯度仅路由至对应的参数子空间：
    - $\nabla_{\theta_b} J_b = \sum_{(n,t)\in I_b^{(r)}} A_{n,t} \nabla_{\theta_b} \ell_{n,t}(\theta)$
  - 由此实现"动作选择"与"参数生成"的优化解耦，避免两者间的参数干扰。

**（2）接口级黑盒 RL 机制——三步构建**

- **接口调用记录捕获**：将 Harness 视为黑盒，在每次智能体交互时捕获精确的输入 token（Token-In）、输出 token（Token-Out）与对齐的采样对数概率（LogProb），形成接口调用记录 $\xi_{e,h,k} = \langle X_{e,h,k}, Y_{e,h,k}, \ell^{roll}_{e,h,k} \rangle$。
- **前缀匹配与树构建**：将每个会话中的调用记录按其 token 前缀关系构建前缀树，合并共享前缀，将重写后的上下文挂接到最长共享前缀处。由此得到会话级树与 rollout 级树集合，每个输出跨度节点对应一个基础训练样本 $S_n = (\xi_n, m_n, \eta_n)$。
- **分段奖励归因**：
  - 结果奖励：$R_{out}^e = \text{F1}_{token}(y_e, y^*_e) \cdot I^{artifact}_e$，在 rollout 组内做归一化得到 $A_{out}^e$；
  - 过程奖励：将可训练的 Action-Args 跨度解析为决策单元，对每个单元计算加权过程信号 $R_{proc}^{e,d} = \sum_v \lambda_v R_v(e,d)$，在相同角色与动作类型的单元组内归一化得到 $A_{proc}^{e,d}$；
  - Token 级对齐：$A_{n,t} = m_{n,t}\left[A_{out}^{e(n)} + \lambda_{proc}\sum_{d \in Q_{e(n)}} \mathbb{I}[(n,t) \in I_{e(n),d}] A_{proc}^{e(n),d}\right]$。

**（3）最终优化目标**

- 采用 rollout 级归一化的剪裁目标（clip 系数 $\epsilon = 0.2$）：
  - $J_{HARNESS-RL} = \frac{1}{K}\sum_{e=1}^K \frac{1}{\max(|I_{train}^e|,1)}\sum_{(n,t)\in I_{train}^e} \min(\rho_{n,t}A_{n,t}, \bar{\rho}_{n,t}A_{n,t})$
  - 其中 $\rho_{n,t} = \exp(\ell_{n,t}(\theta_{r(n)}) - \ell^{roll}_{n,t})$，即当前策略对数概率与 rollout 采样时对数概率之比的指数形式。
  - 按 Action 与 Args 位置拆分为 $J_{action}$ 与 $J_{args}$，CAPO 分别施加梯度路由。

## 6. 论文的主要结论与发现

1. **HARNESS-RL 显著优于现有基线**：Qwen2.5-1.5B 平均 F1 达 42.93，超出最强基线 AgenticRAG-R1 达 15.28 分；Qwen2.5-3B 平均 F1 47.79，超出 14.24 分。在全部 7 个数据集上均取得最优结果。
2. **CAPO 的解耦优化有效**：移除 CAPO 后平均 F1 分别下降 1.89（1.5B）与 1.57（3B）分，验证了冲突感知梯度路由对训练的贡献。
3. **中央策略优化具备显著优势**：在评估场景中，仅中央训练优于所有智能体联合训练（F1：47.79 vs. 45.36）。联合训练增加了不同智能体策略更新之间的干扰，中央独立优化能更好地保持全局规划目标的一致性。
4. **动作与参数存在不同的功能分区**：前向激活分析表明 Action token 与 Args token 在不同层具有不同的重要性分布，为功能分区提供实证依据。
