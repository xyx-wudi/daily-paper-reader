## 摘要
我们提出了首个针对具有转移不确定性的广义和并发随机博弈（CSGs）的概率近似正确（PAC）学习框架，同时解决了纳什均衡（NE）存在性的挑战。我们的算法在转移核上维护数据驱动的$L^1$置信集，并通过求解一个鲁棒CSG来计算社会福利最优的$\varepsilon$-NE，利用基于鲁棒MDP的探索机制来驱动联合状态-动作覆盖。至关重要的是，我们引入了一种纳什边际刻画，使得能够对均衡存在性进行原则性推理：该框架要么返回一个$\varepsilon$-近似NE，其社会福利值在$\varepsilon$-最优范围内，要么提供关于不存在精确NE的可靠证书。在相关状态-动作对满足最小可达性条件$p_{\mathrm{reach}}>0$的情况下，算法在多项式数量的轨迹样本后终止，样本复杂度为$\widetilde{O}\left( {R_{\max}^2 H^4 |S|^2 |A| / (p_{\mathrm{reach}} \varepsilon^2)} \right)$。在基准CSGs上的实验结果表明，该方法具有接近最优的性能、对均衡（不）存在性的正确处理，以及与理论一致的样本复杂度。

## Abstract
We introduce the first Probably Approximately Correct (PAC) learning framework for general-sum concurrent stochastic games (CSGs) with transition uncertainty, while addressing the challenge of Nash equilibrium (NE) existence. Our algorithm maintains data-driven $L^1$ confidence sets over transition kernels and solves a robust CSG to compute a social-welfare optimal $\varepsilon$-NE, using a robust MDP-based exploration mechanism to drive joint state-action coverage. Crucially, we introduce a Nash margin characterisation that enables principled reasoning about equilibrium existence: the framework either returns an $\varepsilon$-approximate NE whose social-welfare value is $\varepsilon$-close to optimal, or provides a sound certificate that no exact NE exists. Under a minimum reachability condition $p_{\mathrm{reach}}>0$ over relevant state-action pairs, the algorithm terminates after a polynomial number of trajectory samples, with sample complexity $\widetilde{O}\left( {R_{\max}^2 H^4 |S|^2 |A| / (p_{\mathrm{reach}} \varepsilon^2)} \right)$. Empirical results on benchmark CSGs demonstrate near-optimal performance, correct handling of equilibrium (non-)existence, and sample complexity consistent with theory.

### 1. 论文的核心问题与整体含义

- **研究动机**：在多智能体随机环境中学习最优策略时，若转移动力学未知，即使很小的估计误差也可能破坏均衡稳定性，使名义上的近似最优策略在真实模型下偏离均衡。并发随机博弈（Concurrent Stochastic Games, CSGs）下玩家同时行动且无法观察他人选择，是此类问题的典型模型。
- **核心困难**：
  1. **均衡存在性**：转移不确定性下，精确平稳NE可能不存在（即使真实博弈存在NE，构建的置信集上也未必存在鲁棒均衡）。需要既能计算近似均衡，又能以原则性方式处理“均衡不存在”的情况。
  2. **全局覆盖**：由于没有单个玩家控制联合动作，且转移核未知，从随机往迹中获得足够的联合状态–动作覆盖非常困难。
- **整体含义**：已有鲁棒规划方法（如RCSG、DRMG）通常假设不确定性集已知或有生成模型；已有PAC学习方法（如MDP、回合制随机博弈）不处理并发、一般和、鲁棒均衡或均衡存在性。本文首次为**一般和CSG在转移不确定下**提供PAC学习框架，并给出可证明的均衡（非）存在性处理方案。

### 2. 论文提出的方法论

- **核心思路**：
  - 维护每个状态-动作对(格点slot)的**数据驱动L1置信集**，利用Weissman的L1集中不等式构造围绕经验核的置信球。
  - 在置信集上构造一个鲁棒CSG（RCSG），用黑盒RCSG求解器计算**社会福利最优的ε-RNE**（鲁棒ε-纳什均衡）。
  - 设计一个**辅助探索RMDP**，将未充分访问的联合状态-动作对的覆盖问题转化为鲁棒可达性问题，从而驱动全局探索。
- **关键概念**：
  - **Nash margin**（纳什边际）：衡量一个策略剖面σ离NE有多近：`μ(σ,P) = min_i min_s inf_{σ'} [u_i(σ,P|s) - u_i(σ_{-i}[σ'],P|s)]`。全局边际 `μ̄=max_σ μ(σ,P*) ≥ 0` 当且仅当存在精确NE；社会福利最优NE的边际记作 `μ*`。
  - **PAC-CSG输出**：分支(a) 返回一个ε-NE且若 `μ̄ ≥ 0` 时为ε-最优；分支(b) 当无精确NE时给出“`μ̄`未定义或`μ̄<0`”的**可靠非存在证书**。
  - **置信集与不确定性**：逐槽位 L1 置信球，半径 `α_t(s,a)`，通过Weissman不等式和失败概率分配（`δ_sa = δ_cont/(|S||A| n(n+1))`）保证对任意时刻`t`，真实核`P*`都以高概率存在于置信集中（事件`E_cont`）。
- **算法框架**：
  1. 初始化：维护访问计数、信心半径、最小样本数`n_min`、可达性常数`p_reach`。
  2. 每轮循环：构建置信集 → 构建L1-CSG → 计算阈值Δ（若`Δ ≤ ε/4`则用求解器解该L1-CSG）→ 否则构建探索RMDP `G_e^t` → 求解探索策略 `σ_e^t` → 执行此策略采样`N_π^t`条轨迹 → 更新访问计数。
- **核心理论步骤**：
  1. **敏感性引理（Lemma 2）**：对任意固定策略剖面，真实核与其L1估计核导致的效用误差不超过 `Δ_t = 1/2 R_max H^2 Δ_t^{L1}`。
  2. **均衡迁移（Lemma 3, Prop 4）**：真实NE近似为置信集上的RNE；若求解器在置信集上失败则说明真实博弈要么无SWNE，要么`μ* < 4Δ_t - ε`。
  3. **探索RMDP（Def 5, Lemma 6）**：用奖赏奖励未知槽位，并用最坏情况（悲观）可达性策略保证真实博弈的每集探索概率不低于 `p_reach`。
  4. **整体PAC保证（Theorem 7）**：结合Freedman不等式处理相关历史事件，最终保证以概率≥1-δ在多项式个样本内终止，样本复杂度为 `O~(R_max^2 H^4 |S|^2 |A|/(ε^2 p_reach))`。
- **无限时域扩展**：假设几乎必然到达目标集，定义`H_eff ≤ |S|/p_T`（Lemma 24）替换`H`，得到相应样本复杂度。

### 3. 实验设计

  6. **Traffic Merge**：安全攸关的多步协调问题。

### 6. 论文的主要结论

1. **近似均衡求解可靠**：在所有存在NE的案例上，算法返回的策略剖面在真实博弈中的值几乎与求解器oracle一致，值差距几乎为0（远小于ε），在允许ε=0.1的情况下实现了接近最优的输出。
2. **均衡非存在检测是健全但非完备的**：
   - 在Cyclic Preferences上，算法在10/10次运行中返回`NOT_FOUND`，给出无精确NE的可靠证书。
   - 在Hide-or-Run上，虽然没有最优平稳策略，但算法返回了一个趋近极限均衡值的ε-NE而非`NOT_FOUND`；这符合“证书在输出时必须正确，但不要求对每个无NE博弈都输出证书”的设定。
3. **探索机制有效**：
   - 均匀随机探索在多个基准上显著低效（最严重为Delayed Coordination样本数多17倍）；
   - 轮询探索在Traffic Merge上多2.3倍样本；
   - 乐观探索与鲁棒探索样本量相近，但在Delayed Coordination上鲁棒值估计偏差更大（值估计差0.06 vs 几乎完美），说明悲观/鲁棒规划在覆盖未知槽位上更稳健。
4. **样本复杂度与理论一致**：经验拟合指数为：`|S|^1.44`, `|A|^0.89`, `H^3.94`, `1/ε^2.11`，与理论界限 `|S|^2 |A| H^4 / ε^2` 一致；其中horizon指数与理论十分吻合。
5. **总体意义**：这是首个支持一般和并发随机博弈的鲁棒PAC学习框架，能同时处理近似均衡计算与均衡不存在的稳健判定。

### 7. 优点

1. **首次性**：首次将鲁棒规划与PAC学习结合到一般和CSG中，填补了该设定下的空白。
2. **均衡存在性的理论刻画**：提出的Nash margin和全局`μ̄`概念将“是否存在精确NE”映射为可计算条件，并支撑健全的非存在证书逻辑，这在多智体学习中很精巧。
3. **探索与鲁棒性**：利用RMDP的鲁棒可达性来解决联合状态-动作覆盖问题，比乐观或均匀探索更可靠；对不同历史依赖的事件使用Freedman不等式进行鞅论证，保证概率化覆盖和终止。
4. **理论边界完整**：给出有限时域和无限时域目标统一的分析方法，利用了有效视界和规范化SSP假设。
5. **实验验证严谨**：既有理论验证又有小型但多样的基准测试，提供公平的探索策略对比（控制其他环节不变），并附上完整结果表和学习动力学分析。

### 8. 不足与局限

1. **集中式探索假设（A1）**：需要一个中心学习者同时控制两个玩家；实际中多智能体往往是分布式/对抗式的，并不总能满足。
2. **可达性条件（A2）**：要求所有相关槽位在某个策略下可达概率均大于多个下界 `p_reach>0`；无穷时域还要求近乎必然达目标且下界`p_T>0`。在许多实际博弈中这些条件不一定成立。
3. **图保持假设（A3）**：要求不确定性集合与真实核拥有相同支撑，不能处理罕见转移或支撑失配。
4. **黑盒求解器**：计算SWNE依赖PRISM-games这类符号求解器，一般和CSG均衡求解是PSPACE-complete，扩展到大状态和大动作空间会遇到指数瓶颈；算法本身的信息论PAC保证不包含求解器计算复杂度。
5. **样本复杂度依赖H^4**：可能可优化到H^3，但需要更强条件或更精细浓度分析；`n_min` 中依赖`|S|/ε²`，但实际总样本由少数“硬探索”槽位主导（附录K.2显示收敛由最难采样槽位决定）。
6. **非存在证书不完备**：当真实博弈没有精确NE时，算法可以被允许返回ε-NE而不输出证书（在Hide-or-Run中体现）；虽然这是理论固有的性质，但可能令实际用户困惑。
7. **实验规模有限**：只在小模型上测试（状态数至多几十，动作数至多64），未涉及更大规模、复杂真实或高维状态空间；没有报告运行总时长和GPU等资源，可复现性相对有限。
8. **算法对奖励上界、支持已知等有预先知识依赖**；如果`R_max`未知或支持估计不准，置信半径和探索保证需要调整，论文没有讨论。
