## 摘要
协作多智能体强化学习（MARL）系统依赖过往经验来学习协调行为，但若在训练期间环境或任务目标发生变化，这些经验可能变得不可靠。在这种情况下，智能体首先需要一种方法来识别情况已发生变化，然后再决定如何适应。本文研究基于奖励派生信号的协作MARL在线变化点检测。我们提出了“过往奖励模式”（PPR），一种轻量级、与算法无关的检测器，它平滑智能体的回报流，强调近期变化，并应用统计漂移检测器来标记显著变化。我们在基于多智能体粒子环境的自定义“说话者-听者”环境中，在两种受控非平稳情景下评估PPR。结果表明检测速度与警报稳定性之间存在权衡。平滑回报基线能更早检测，但会产生大量重复警报。相比之下，将检测器直接应用于原始回报常常会漏掉变化。PPR通过限制冗余检测同时仍能识别受控变化，提供了一种更平衡的方法。这些发现凸显PPR作为一种轻量级、基于奖励的监控工具，能使协作MARL系统在训练期间可靠地识别重大变化。

## Abstract
Cooperative multi-agent reinforcement learning (MARL) systems rely on past experience for learning coordinated behaviour, but this experience may become unreliable if the environment or task objective changes during training. In such cases, agents first need a way to recognize that the situation has changed before deciding how to adapt. This paper studies online change-point detection for cooperative MARL using reward-derived signals. We propose \emph{Patterns of Past Rewards} (PPR), a lightweight algorithm-agnostic detector that smooths agents' return streams, highlights recent changes, and applies a statistical drift detector to flag significant shifts. We evaluate PPR in a custom Speaker-Listener environment based on the Multi-Agent Particle Environment under two controlled non-stationarity scenarios. Our results show a trade-off between detection speed and alarm stability. A smoothed-return baseline detects earlier but produces many repeated alarms. In contrast, applying the detector directly to raw returns often misses the shift. PPR offers a more balanced approach by limiting redundant detections while still identifying the controlled shifts. These findings highlight PPR as a lightweight, reward-based monitoring tool that enables cooperative MARL systems to reliably identify major changes during training.

## 2. 论文提出的方法论：核心思想、关键技术细节

- **方法论名称**：PPR（Patterns of Past Rewards，过往奖励模式）。
- **核心思想**：PPR不修改底层MARL算法，仅作为旁路监控器，读取训练产生的回合回报流，通过一系列变换与统计检验，识别回报分布的显著变化。
- **完整处理流程**：`Re → SMA → ¯Re → EMV → Ve → KSWIN → de`（其中Re为回合回报，SMA为简单移动平均，EMV为指数移动方差，KSWIN为滑动窗口KS检验，de为二值漂移指示符）。
- **关键技术细节与公式**：
    - **简单移动平均 (SMA)**：用于平滑原始回报流中的高频波动（如探索噪声），获得近期回报的局部趋势。给定窗口w，平滑回报为 `¯Re = (1/w) * Σ(i=e-w+1 to e) Ri`。存在一定热身期。
    - **指数移动方差 (EMV)**：用于强调平滑回报轨迹的变化。公式为 `Ve = β(¯Re - ¯Re-1)^2 + (1-β) Ve-1`。该步骤将平滑回报的变化转换为正向变异性信号，使突变或变异性爆发在KSWIN检测前更加显著。
    - **KSWIN漂移检验**：最终阶段使用KS检验比较最近测试窗口与参考窗口的经验累积分布函数。统计量为 `D = sup_x |FA(x) - FB(x)|`，临界阈值为 `τα = sqrt(-ln(α) / m)`，当D > τα时判定发生漂移。

## 3. 实验设计：数据集/场景、基准方法与对比方法

- **测试环境**：基于**多智能体粒子环境 (MPE)** 的自定义**说话者-听者 (Speaker-Listener)** 协作任务。环境中一个智能体（说话者）观察目标颜色并传递消息，另一个智能体（听者）结合消息和地标位置执行移动。两者共享团队奖励。
- **非平稳场景**：训练中引入两类受控变化：

- **训练与检测协议**：使用MADDPG算法在线训练，共1,000,000步。受控变化在第500,000步（即第20,000个回合）时引入。PPR作为旁路模块运行，不干预学习过程。
- **对比方法（消融实验）**：
    1.  **PPR**（完整流程：SMA → EMV → KSWIN）。
    2.  **SMA + KSWIN**：移除EMV阶段，将平滑回报直接送入KSWIN。
    3.  **Raw return + KSWIN**：移除SMA和EMV预处理，将原始回合回报直接送入KSWIN。
- **评估指标**：
    - **检测延迟**：真实变化点与首个报警之间的回合数。
    - **变化前误报数**：真实变化点前的报警次数，衡量虚假报警。
    - **多余检测数**：首次正确检测后，多余重复报警的数量。
