## 摘要
多智能体强化学习（MARL）通常从零开始训练去中心化策略，要求智能体同时获得个体任务能力和协调能力。然而，许多多智能体问题存在一个兼容的单智能体对应问题，其中的底层任务可以孤立地学习。我们提出面向现有单智能体策略的多智能体观测变换（MATES），这是一个输入侧自适应框架，适用于多智能体观测在保留单任务信息的同时还显露出可单独识别的邻居信息的任务。MATES 从多智能体经验中学习一个小型适配器，将该观测映射为冻结的单智能体策略所期望的格式，从而在不更新单智能体策略本身的情况下，诱导出适合共享环境的动作。MATES 保持预训练策略的内部架构不变，并保留底层 MARL 算法的目标和更新过程。我们在终身路径规划、导航和协作发现任务上，使用同策略和异策略算法评估 MATES，涵盖离散和连续的观测空间与动作空间。在所有评估设置中，MATES 优化的参数量仅为全策略训练的 3.5–7.3%，同时始终优于从零开始的 MARL 训练。它接近全量微调的性能，整体上与基于演示的基线方法相比仍具竞争力，并在训练中未遇到的团队规模下保持较强的任务性能。这些结果提供证据表明，在这种观测结构下，无需修改编码个体能力的策略，也能学习到有效的多智能体行为。

## Abstract
Multi-agent reinforcement learning (MARL) commonly trains decentralized policies from scratch, requiring agents to acquire individual task competence and coordination simultaneously. Yet many multi-agent problems admit a compatible single-agent counterpart in which the underlying task can be learned in isolation. We introduce Multi-Agent Observation Transformation for Existing Single-Agent Policies (MATES), an input-side adaptation framework for tasks whose multi-agent observations preserve the solo-task information while exposing separately identifiable neighbor information. From multi-agent experience, MATES learns a small adapter that maps this observation into the format expected by a frozen single-agent policy, inducing actions suited to the shared environment without updating the single-agent policy itself. MATES leaves the pretrained policy's internal architecture unchanged and retains the objectives and update procedures of the underlying MARL algorithm. We evaluate MATES using both on- and off-policy algorithms on lifelong pathfinding, navigation, and cooperative discovery, spanning discrete and continuous observation and action spaces. Across all evaluated settings, MATES optimizes only 3.5-7.3% as many parameters as full-policy training while consistently outperforming MARL training from scratch. It approaches the performance of full fine-tuning, remains competitive overall with demonstration-based baselines, and retains strong task performance at team sizes not encountered during training. These results provide evidence that, under this observation structure, effective multi-agent behavior can be learned without modifying the policy that encodes individual competence.

## 一、核心问题与整体含义

- **研究背景**：多智能体强化学习（MARL）通常从零训练去中心化策略，智能体必须同时学习“个体任务能力”和“多智能体协调”，并面临非平稳性问题：其他智能体策略不断变化，环境对每个智能体而言不再稳定。
- **关键观察**：许多多智能体问题存在兼容的单智能体对应任务。例如单个机器人导航只需到达目标，而多机器人导航还需避碰与协调。单智能体阶段已经学到的“朝目标移动、沿路径前进、搜索目标”等能力，在多智能体环境中仍有价值。
- **核心假设**：当多智能体观测可分解为 `(o_i, N_i)` 时，`o_i` 保留单智能体任务信息，`N_i` 提供邻居智能体信息。因此，可以不修改编码个体能力的单智能体策略，仅通过输入侧观测变换来适配多智能体交互。
- **研究问题**：能否在不修改已编码个体能力的策略的前提下，学习有效的多智能体行为？
- **整体含义**：论文提出 MATES，将单智能体策略冻结，仅训练一个小型观测适配器，把多智能体观测映射为单智能体策略可接受的输入，从而以极少参数实现多智能体协调。

## 二、方法论

- **核心思想**：两阶段训练。
  - 第一阶段：在单智能体对应任务中训练单智能体策略 `π_solo,θ`，获得个体任务能力。
  - 第二阶段：将 `π_solo,θ` 迁移到多智能体任务并冻结参数 `θ`，在其输入前加入可训练观测适配器 `C_ϕ`。
- **观测变换**：对每个智能体 `i`，多智能体观测为 `\bar o_i = (o_i, N_i)`，其中 `o_i` 为单智能体观测，`N_i` 为邻居信息。适配器输出：
  - `\tilde o_i = C_ϕ(o_i, N_i)`，且 `\tilde o_i ∈ O_solo`。
  - 组合策略为：`π_MATES,ϕ(a_i | \bar o_i) = π_solo,θ(a_i | C_ϕ(\bar o_i))`。
- **梯度与冻结机制**：虽然 `π_solo,θ` 被冻结，但它仍处于可微计算图中。梯度可穿过冻结策略回传到适配器 `C_ϕ`，只更新 `ϕ`，不更新 `θ`。
- **与底层 MARL 算法兼容**：MATES 保留底层 MARL 算法的目标函数和更新流程，只增加轻量组件并限制优化范围。
- **Actor-Critic 扩展**：
  - Actor 侧：冻结单智能体 actor，训练 actor 观测适配器。
  - Critic 侧：冻结单智能体 critic，训练 critic 观测适配器；对 Q  critic 使用联合观测-动作适配器。
  - 可选变体：`MATES` 额外训练迁移 critic 的价值头；`MATES-NH` 保持价值头冻结，仅训练适配器。
- **参数共享**：实验中对同质智能体使用共享适配器，使可训练参数量不随团队规模增长。算法流程可概括为：先单智能体 RL 训练 `π_solo`；冻结 `θ`；初始化适配器；用 MARL 算法在多智能体环境训练适配器；返回 `π_MATES`。

## 三、实验设计

- **任务与 benchmark**：
  - **POGEMA**：离散网格终身多智能体路径规划，智能体到达目标后分配新目标。指标为吞吐量 throughput，即每环境步到达目标数，越高越好。训练团队规模 `n=64`。
  - **VMAS Navigation**：连续控制导航，智能体到达各自目标并避免碰撞。指标为回合长度，越低越好。训练团队规模 `n=8`。
  - **VMAS Discovery**：连续控制协作发现，智能体覆盖目标，目标被覆盖后重生。指标为回合内覆盖目标数，越高越好。训练团队规模 `n=8`。
- **学习算法**：
  - 使用 IPPO（同策略）和 ISAC（异策略）。
  - POGEMA 使用 IPPO；Navigation 和 Discovery 同时使用 IPPO 与 ISAC。
  - 基于 BenchMARL 实现。
- **网络架构**：
  - POGEMA 使用 Follower 风格共享 64 通道 ResNet 编码器，适配器为两层 CNN、32 隐藏通道。
  - VMAS 使用 BenchMARL 标准骨干：IPPO 为两层宽 256 actor/critic MLP；ISAC 为 actor 加双 Q 网络。适配器为一层宽 64 MLP。
- **对比方法**：
  - **Solo**：直接部署单智能体策略，无邻居信息、无多智能体训练。
  - **Classic MARL**：从随机初始化训练完整参数共享策略。
  - **Full fine-tuning**：扩展输入层接收多智能体观测，迁移预训练权重并微调整个网络。
  - **PegMARL**：基于个性化专家演示和判别器奖励塑形的 MARL 基线。
  - **R2BC**：轮转行为克隆，用冻结专家按轮转为新策略提供动作标签。
  - **MATES 与 MATES-NH**：本文方法及其无价值头训练变体。
- **评估指标**：直接使用任务完成指标，而非优化奖励；曲线和区间为 30 个留出评估回合的均值与 95% 置信区间。
