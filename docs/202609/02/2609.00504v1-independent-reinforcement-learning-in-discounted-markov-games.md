## 摘要
在这项工作中，我们研究了折扣一般和马尔可夫博弈中的完全非耦合学习。假设“PPAD的ETH”，我们证明，对于每个固定的折扣因子，当玩家在去中心化环境中独立学习时，不存在多项式时间算法来计算折扣一般和马尔可夫博弈中逆多项式精度的粗相关均衡。作为这一困难结果的补充，我们提供了似乎是第一个具有次指数收敛保证的完全非耦合算法，该算法可在不施加任何博弈结构限制的情况下，收敛到折扣一般和马尔可夫博弈中的粗相关均衡。我们的算法是乐观镜像下降的分层变体，其步长计划递增，并针对多智能体环境进行了调整。最后，我们为上述算法开发了完全反馈和部分反馈的版本，并为每种情况建立了次指数收敛保证。

## Abstract
In this work, we study radically uncoupled learning in discounted general-sum Markov games. Assuming ``$\mathsf{ETH}$ for $\mathsf{PPAD}$", we show that, for every fixed discount factor, there is no polynomial-time algorithm for computing inverse-polynomially accurate coarse correlated equilibria in discounted general-sum Markov games when players learn independently in decentralized settings. Complementing this hardness result, we provide what appears to be the first \emph{radically uncoupled} algorithm with sub-exponential convergence guarantees to coarse correlated equilibria in discounted general-sum Markov games without imposing any structural restrictions on the game. Our algorithm is a \emph{layered} variant of optimistic mirror descent with an increasing step-size schedule tailored to the multi-agent setting. Finally, we develop both full-feedback and partial feedback versions of the aforementioned algorithm and establish sub-exponential convergence guarantees for each case.

### 1. 核心问题与整体含义（研究动机与背景）

- **研究领域**：多智能体强化学习（MARL），重点聚焦于**一般和折扣马尔可夫博弈（discounted general-sum Markov games）** 中的均衡计算，其标准数学模型为随机博弈（Markov games），同时覆盖单智能体 MDP 与一般和博弈的动态交互特性。
- **核心问题**：在 **radically uncoupled**（完全非耦合/独立）信息结构下，每个玩家无法观测他人的策略、损失、价值函数或随机比特，彼此之间既无共享随机性也无法通信。在该极强去中心化约束下，是否能够设计**（准）高效**的学习算法，计算折扣一般和马尔可夫博弈的粗相关均衡（CCE）？
- **双层次挑战**：
  - 与单人 MDP 不同，策略的优劣取决于对手策略；
  - 与静态一般和博弈不同，历史依赖的非马尔可夫偏移会通过转移核改变未来状态分布，使比较分布本身随时间变化且对玩家不可知。
- **研究空白**：已有正面结果多依赖协调机制、共享随机数或集中式后处理；已有分布式算法如 V-learning、SPoCMAR 无法提供在线 self-play 后悔保证。论文正是针对上述空白，同时回答"能有多好"（上界）与"能有多难"（下界）两个问题。

### 2. 方法论

论文提出**分层乐观在线镜像下降（Layered Optimistic Online Mirror Descent, Layered OOMD）** 算法，并配套建立下界定理，整体框架分三大部分：

- **算法设计上界（正问题）**
  - 在有限时域一般和马尔可夫博弈（未打折）中运行 self-play。
  - 每名玩家在每个状态-层节点维护策略，Q 函数反馈驱动更新，更新公式为带 Bregman 散度的乐观镜像下降：
    - $x_{t,h}^{i,s} = \arg\min_{x\in\Delta(A_i)} \left\{ \eta_h \langle Q_{t-1,h}^i(s,\cdot), x\rangle + D_i(x, \tilde{x}_{t-1,h}^{i,s})\right\}$
  - **正则子**：采用**平滑负熵** $\Psi_i(x) = \sum_{a}(x(a)+\lambda_i)\log(x(a)+\lambda_i)$（$\lambda_i = 1/|A_i|$），使 Bregman 直径有限，且保证 Lipschitz 性质。
  - **分层递增步长**：第 $h$ 层的学习率为 $\eta_h = \eta_0 T^{-\alpha_h}$，$\alpha_h = \frac{3(H-h)+1}{3H+1}$。浅层步长小、策略演化慢，深层步长大、适应快，由此构造嵌套时间尺度分离，抑制"历史占据权重"漂移。
  - 【定理 1】在完全反馈下经过 $T_\varepsilon = \left(\frac{C_{SE}^*}{\varepsilon}\right)^{(3H+1)/3}$ 轮后得到 $\varepsilon$-近似 CCE，即后悔率 $O(T^{-3/(3H+1)})$。
- **部分反馈扩展**
  - 玩家只能观察到自己的经历轨迹，无法看到精确 Q 矩阵，因此采用 **分块估计**：一个块内固定相同策略 $B$ 个周期，用轨迹样本构造 Q 估计 $\hat{Q}_{k,h}^i(s,a^i)$。
  - 需假设 $(\kappa,\zeta)$-可达性，使各状态有足够访问概率；采用 $\zeta$-探索下限与**比较器平滑技术**（将任意历史依赖策略与均匀分布凸组合）。
  - 【定理 2】在 $(\kappa,\zeta_\varepsilon)$-可达条件下，以高概率得到 $\varepsilon$-近似 CCE，总周期复杂度保持对 $H$ 的指数依赖并叠加多项式估计开销。
- **折扣场景的传输原理**
  - 借助折扣尾误差上界 $\tau_{L,\bar{H}}(\gamma) \le \gamma^L/(1-\gamma)$：先用有限时域算法计算前 $L$ 层的策略，再以均匀参考策略续接到原博弈；若取 $L_\varepsilon = O(\log(1/\varepsilon))$，可把指数误差清零并得到**准多项式**复杂度。
  - 【推论 1（全反馈）】与【推论 2（部分反馈）】分别给出折折扣 CCE 的准多项式时间/样本保证，不需要任何博弈结构限制。
- **计算下界（负问题）**
  - 通过将双矩阵博弈 $M$ 嵌入对数时域马尔可夫博弈 $FH(M)$（每次奇数层记录玩家动作，偶数层归零），再嵌入固定折扣因子的无限时域博弈 $\widetilde{F}_{H,\gamma}(M)$，建立了从双矩阵博弈 NE 到折扣马尔可夫博弈稀疏 CCE 的多项式时间归约。
  - 结合 Rubinstein（2016）在 **ETH for PPAD** 假设下的双矩阵博弈难解性结论，【定理 5】/【推论 3】证明：对每个固定折扣因子 $\gamma\in(0,1)\cap\mathbb{Q}$ 和任意多项式支撑界 $C$，都存在逆多项式精度 $\varepsilon = O(N^{-K})$，使任何多项式时间算法都无法计算 $(N^C, N^{-K})$-稀疏近似 CCE。

### 6. 主要结论与发现

- **正定理**：
  - 提出首个在 **radically uncoupled** 信息结构下、无需任何结构限制即可获得次指数收敛保证的算法（分层 OOMD）；
  - 完全反馈后悔率为 $O(T^{-3/(3H+1)})$；部分反馈在可达性假设下保持同阶 $H$ 指数依赖并额外添多项式估计项；
  - 折扣设定下借助截断论证，将有限时域结果升级为准多项式时间/样本复杂度的折扣 CCE 求解器（对全/部分反馈均有效）。
- **负定理**：
  - 若假设 $\mathsf{ETH\ for\ PPAD}$，对任意固定 $\gamma\in(0,1)\cap\mathbb{Q}$ 与任意多项式支撑界，不存在多项式时间算法能计算逆多项式精度的稀疏折扣 CCE，即使允许集中式访问博弈全部描述。
- **整体启示**：折扣一般和马尔可夫博弈的在线、独立、非协调自学习问题，其最优可能的复杂度很可能为准多项式；论文用上界与下界将复杂度刻画压缩到很窄的区间内，填补了该方向的理论空白。

### 7. 优点

- **理论创新性强**：
  1. 首次在**无结构限制**的一般和折扣马尔可夫博弈中提供独立学习（radically uncoupled）的次指数收敛算法，信息结构约束十分苛刻，对算法设计的要求很高；
  2. 分层递增步长配合平滑熵的"固定份额"思想解决了历史占据权重漂移这一核心障碍；
  3. 有限时域到折扣场景的**截断传输引理**清晰优雅，使得结论同时覆盖有限-与无限时域；
  4. 上下界相结合，证明了准多项式复杂度是当前复杂性理论下的"最佳期望"，解释力强。
- **隐私/分布式可部署性强**：算法无需状态共享或公共随机源，更新仅依赖每个玩家自身的反馈，适合通信受限、延迟敏感或隐私受限场景。
- **部分反馈的分析**：引入分块估计划与 $(\kappa,\zeta)$-可达性，把统计估计误差和策略运动误差解耦，保留了相同主阶收敛特性，符合真实 MARL 场景的可用性。

### 8. 不足与局限

- **复杂性差距仍然存在**：上界是准多项式、下界是超多项式但弱于指数，未精确判定问题的多项式-准多项式最优复杂度；若不做 $\mathsf{ETH\ for\ PPAD}$ 假设，该问题是否可能落入其他复杂度类别仍未知；
- **均匀可达性假设较强**：部分反馈算法要求每块内每个状态-动作对以至少 $\kappa\zeta/|A|$ 概率被访问，这在很多实际大规模状态空间或探索受限环境中难以满足；作者也未能给出更弱的可学习条件；
- **对策略类的局限**：在线后悔保证中的比较策略是任意历史依赖策略，但没有回答将比较策略限制为马尔可夫策略时，复杂度是否可降至多项式；
- **实验深度不足**：缺少大规模基准实验和消融研究，没有与既有去中心化算法进行严格计算时间/样本复杂度对比，无法定量展示真实运行效率；
- **参数设定偏理论化**：步长计划、块长、可达性参数强烈依赖游戏结构（如 $H, \kappa, \zeta, A_{\max}$），实际应用中需要可靠估计这些参数的先验边界；
- **应用层面的限制**：聚焦 CCE 而非 NE 或 CE，CCE 在个体偏离的保护意义较薄弱；在需要强个体稳定性或需要收敛到纳什均衡的任务中，该理论并不能直接适用。
