## 摘要
在本工作中，我们提出了一种用于多智能体避碰的去中心化通信条件生成式框架。智能体使用流匹配策略生成短时域动作序列，该策略由可访问全局状态的特权离线示范训练得到。示范中不包含显式通信信号；相反，智能体学习在部分可观测下交换并聚合编码交互相关意图的潜在消息。该形式支持测试时的灵活推理：无条件生成对应于独立行为，而通信条件生成则无需集中式规划即可实现协同交互。由此得到的策略在执行时以完全去中心化的方式运行，仅依赖局部观测和学习到的消息。结合滚动时域推理方案，所提方法能够高效地单步推理短时域动作序列，并在通信中断时平滑退化。大量仿真结果表明，该方法具有接近专家的避碰性能，对更密集、未见过的多智能体场景具有强泛化能力，并且能够零样本迁移到真实机器人实验。

## Abstract
In this work, we propose a decentralized communication-conditioned generative framework for multi-agent collision avoidance. Agents generate short-horizon action sequences using a flow-matching policy trained from privileged offline demonstrations with access to global state. The demonstrations do not include explicit communication signals; instead, agents learn to exchange and aggregate latent messages that encode interaction-relevant intent under partial observability. This formulation supports flexible inference at test time, where unconditioned generation corresponds to independent behavior and communication-conditioned generation enables coordinated interaction without centralized planning. The resulting policies operate in a fully decentralized manner at execution time, relying only on local observations and learned messages. Combined with a receding-horizon inference scheme, the proposed approach enables efficient single-step inference of short-horizon action sequences and degrades gracefully under communication dropouts. Extensive simulation results demonstrate near-expert collision avoidance performance and strong generalization to denser, unseen multi-agent scenarios, along with zero-shot transfer to real-robot experiments.

## 2. 论文提出的方法论

### 核心思想
- 用**特权专家（CADRL）的离线示范**训练流匹配生成策略，输出短时域动作序列。
- 示范中**不含显式通信信号**，通信通过端到端优化在部分可观测下自发涌现：智能体学习交换并聚合编码交互意图的潜在消息。
- 推理时支持灵活条件化：无条件生成 ≈ 独立行为；通信条件生成 ≈ 无需集中规划的协调交互。

### 关键技术细节

- **问题建模**：
  - 每个智能体为圆形机器人，采用独轮车动力学，控制量为速度调整与航向变化 \(a_i = [v_i, \Delta\theta_i]^\top\)。
  - 观测为自中心坐标下的局部向量（到目标距离、目标相对航向、偏好速度、自身半径，以及最近邻智能体的相对位置/速度投影）。
  - 策略每次输出长度为 \(K\) 的短时域动作序列 \(A_i^{(t)} \in \mathbb{R}^{K\times 2}\)，仅执行第一个动作，形成滚动时域控制。

- **通信模块**：
  - **消息发射**：共享编码器 \(M_{\theta_1}\) 将局部观测压缩为潜在消息 \(m_i^{(t)}\)。
  - **成对交互编码**：对有序智能体对 \((i,j)\) 生成交互 token \(z_{ij}^{(t)} = I_{\theta_2}(m_i, m_j)\)，并计算兼容性分数 \(\alpha_{ij}^{(t)}\)。
  - **注意力聚合**：对分数做 softmax 归一化得到权重 \(w_{ij}\)，聚合得到 \(\bar{m}_i^{(t)} = \sum_{j\neq i} w_{ij} z_{ij}\)，可解释为对他人交互相关信息的"软共识"。聚合具有置换不变性，且仅依赖本地交换消息，保持去中心化。

- **条件生成策略（流匹配）**：
  - 定义线性插值 \(A_\tau = \tau A_i^{(t)} + (1-\tau)\epsilon\)，学习条件速度场 \(u_\theta(A_\tau, o_i^{(t)}, \tau, \bar{m}_i^{(t)})\)。
  - **条件流匹配损失** \(L_{CFM}\)：训练模型恢复最优传输向量场，梯度同时回传至生成策略和通信模块。
  - **无条件流匹配损失** \(L_{UFM}\)：不含通信条件，仅用于正则化基础生成动力学、稳定训练，不向通信模块传梯度。

- **特权教师与蒸馏**：
  - 教师为基于 Transformer 的交互编码器 \(T_\phi\)，输入为各智能体局部观测加**仅训练时可用的全局参考信息**，输出智能体级潜在意图嵌入 \(h_i^{(t)}\)。
  - 教师通过重建目标 \(L_{intent}\) 训练，使其嵌入足以预测智能体下一时刻观测。
  - **蒸馏**：复用教师的解码器 \(D_\psi\)，对通信模块的聚合消息 \(\bar{m}_i^{(t)}\) 施加辅助损失 \(L_{aux}\)，但梯度只传至通信参数、不更新解码器，防止平凡编码坍塌。

- **总损失**：\(L_{total} = L_{CFM} + \lambda_1 L_{UFM} + \lambda_2 L_{aux} + L_{intent}\)，其中 \(L_{CFM}\) 为主导信号，辅助损失仅塑造表示几何、稳定训练。

- **去中心化推理与滚动时域执行**：
  - **首步初始化**：从高斯噪声出发，用 \(S\) 步欧拉积分生成动作序列。
  - **热启动**：后续时间步从上一时刻预测序列出发，用高斯噪声部分扰动（\(\alpha = 1 - 1/S\)），在 \(\tau = \alpha\) 处做单步去噪。
  - **执行**：仅执行第一个动作，重复该过程。该设计带来时间一致性、自然平滑性，并在通信中断时提供合理回退方案；每步仅需一次速度场评估，适合实时控制。

- 所提方法在 4 智能体（训练规模）和 8 智能体（泛化）场景下均持续优于去中心化基线，接近特权控制器的性能。
