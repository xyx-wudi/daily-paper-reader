## 摘要
研究了具有未知动力学、外部扰动以及执行器通道上虚假数据注入（FDI）攻击的非线性多智能体系统的领导者-跟随者编队控制问题。该问题被建模为零和微分博弈，并利用积分Bellman-Isaacs方法求解。为处理输入饱和约束，在优化问题中引入非二次控制代价函数，从而得到有界控制律。此外，本文提出一种代价函数构造方法并开发了评论家学习律，二者共同保证系统的实际固定时间稳定性，同时克服了现有固定时间强化学习公式的局限性。最后，严格证明了评论家权重估计误差和领导者参考编队跟踪误差实际固定时间收敛到有界残差集。仿真结果验证了所提方法在外部扰动、FDI攻击和输入约束下的有效性。

## Abstract
The leader-follower formation control problem is investigated for nonlinear multi-agent systems with unknown dynamics, external disturbances, and false data injection (FDI) attacks on actuator channels. The problem is formulated as a zero-sum differential game and solved using the Integral Bellman-Isaacs approach. To address input saturation constraints, a non-quadratic control cost function is incorporated into the optimization problem, leading to a bounded control law. Furthermore, this paper proposes a cost function construction method and develops a critic learning law, which together guarantee the practical fixed-time stability of the system while overcoming the limitations of existing fixed-time reinforcement learning formulations. Finally, the practical fixed-time convergence of both the critic weight estimation error and the leader-referenced formation tracking error to bounded residual sets is rigorously proven. Simulation results demonstrate the effectiveness of the proposed method under external disturbances, FDI attacks, and input constraints.

### 1. 核心问题与研究动机

- 论文研究的是**执行器通道遭受虚假数据注入（FDI）攻击的非线性多智能体系统**的领航–跟随编队控制问题。
- 系统面临三重复杂性：
  - **未知非线性动力学**：各跟随者的漂移动力学未知，传统基于模型的控制方法难以适用；
  - **外部扰动与FDI攻击**：攻击信号通过执行器通道注入，会沿通信图传播，破坏编队集体行为；
  - **输入饱和约束**：安全控制输入必须限制在给定幅值范围内。
- 现有工作的不足：
  - 直接求解Hamilton–Jacobi–Isaacs（HJI）方程对于非线性系统通常是不可行的，且需要已知系统漂移；
  - 已有固定时间强化学习研究（如文献[14]）仅针对结构较简单的二阶多智能体系统，无法直接推广到一般未知非线性动力学；
  - 现有固定时间强化学习公式往往将固定时间衰减不等式直接强加于未知值函数，缺乏如何在实际中生成该结构的构造性设计。
- 针对上述挑战，作者提出**基于积分强化学习与零和微分博弈**的统一框架，以实现固定时间收敛与编队安全控制的最优折中。

### 2. 方法论

#### 2.1 整体思路
- 将问题建模为**局部零和图博弈**：社会控制输入 \(u_{ci}\) 为最小化器，扰动与攻击的组合信号为最大化器；
- 采用**积分Bellman–Isaacs恒等式**，消除未知系统漂移对学习过程的影响；
- 通过在成本函数中嵌入**非二次饱和兼容效用函数**导出有界双曲正切形式的鞍点策略；
- 通过对状态惩罚引入**两项幂次结构**（低于二次与高于二次混合），使HJI方程自然生成固定时间衰减所需的比较项，而不是对未知值函数作外部假设。

#### 2.2 关键技术细节
- **代价函数构造**：
  \[
  Q_{ii}(\chi_i)=\chi_i^\top Q_i\chi_i+\kappa_{i1}\|\chi_i\|^{2\alpha_i}
  +\kappa_{i2}\|\chi_i\|^{2\beta_i}
  \]
  其中 \(0<\alpha_i<1<\beta_i\)，这一设计使低阶项和高阶项分别对应固定时间收敛的两个阶段。
- **饱和控制效用**：
  \[
  U_i(u_{ci})=2\sum_{\ell=1}^m \bar u_{i\ell}r_{i\ell}
  \int_0^{u_{ci,\ell}}\tanh^{-1}(s/\bar u_{i\ell})\,ds
  \]
  由此导出的最优安全控制为有界策略：
  \[
  u^*_{ci}=-\bar U_i\tanh\!\left(\frac12 R_i^{-1}\bar U_i^{-1}
  G^{\chi\top}_{ii}(x_i)\nabla V_i^*\right)
  \]
- **积分Bellman–Isaacs残差**：沿鞍点轨迹对值函数导数积分，得到不含未知漂移的有限窗口恒等式；利用RBF神经网络近似值函数，定义在线与经验重放的残差。
- **固定时间Critic更新律**：
  \[
  \dot{\hat W}_i=-\Gamma_i\left(\psi_i s_i+\sum_{k=1}^{M_i}\psi_{ik}s_{ik}\right)
  -\sigma_i\Gamma_i\hat W_i
  \]
  其中残差目标为两项幂次结构：低阶幂 \(p_i\in(0,1)\) 加速残差接近零时的学习，高阶幂 \(q_i>1\) 防止残差较大时学习变慢，二者结合实现固定时间收敛。
- **实际固定时间稳定性**：通过Lyapunov分析（结合积分窗口与critic权重误差的组合Lyapunov函数），严格证明critic权值估计误差与编队跟踪误差在固定时间内收敛至有界残差集，收敛时间与初始条件无关。
