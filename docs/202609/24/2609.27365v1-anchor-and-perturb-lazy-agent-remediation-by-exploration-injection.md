## 摘要
锚定与扰动（Anchor and Perturb, AnP）是一个轻量级框架，通过将探索方差注入与递归流形稳定性解耦，解决多智能体协调失败问题。现有补救策略主要改变混合网络架构，或在群体中强制同时探索，这不可避免地在非单调奖励空间中引发严重的时间差分惩罚。具体而言，AnP 隔离表现不佳的懒惰智能体，并向目标坐标注入非对称探索脉冲，同时将已收敛的队友锚定到名义贪心利用。实证遥测基准表明，AnP 成功挽救了崩溃的联合策略（从 5% 的评估胜率最低点恢复到 85%），并促进摆脱次优协调平台期，在无需修改网络结构的情况下维持 90% 的峰值胜率。

## Abstract
Anchor and Perturb (AnP) is a lightweight framework that resolves multi-agent coordination failures by decoupling exploratory variance injection from recurrent manifold stability. Existing remediation strategies predominantly alter mixing network architectures or enforce simultaneous exploration across the collective, which inevitably precipitates severe temporal-difference penalties in non-monotonic reward spaces. Specifically, AnP isolates underperforming lazy agents and injects an asymmetric exploratory pulse into targeted coordinates whilst anchoring converged teammates to nominal greedy exploitation. Empirical telemetry benchmarks demonstrate that AnP successfully rescues collapsed joint policies (recovering from a 5% evaluation win rate nadir back to 85%) and facilitates escape from suboptimal coordination plateaus, sustaining peak win rates of 90% without requiring structural network modifications.

## 1. 核心问题与整体含义（研究动机与背景）

- **问题定位**：在 CTDE（集中训练、分散执行）框架下的合作型多智能体强化学习（MARL）中，值分解方法（QMIX、WQMIX、QPLEX）常出现**非对称收敛**：部分智能体学到接近最优的协作策略，而另一些智能体仍停留在只能获得边际回报的局部次优动作上，成为所谓"懒惰智能体"（lazy agent），拖累整体团队回报。
- **根因分析**：
  - 现代混合网络施加**单调性约束**（∂Q_tot/∂Q_i ≥ 0），在非单调协调地形中会诱发**相对过度泛化**（relative overgeneralization）。
  - 常规探索是**对称的（M = N）**：当表现差的智能体尝试探索时，已收敛的队友也被迫同时探索，导致"探索碰撞"，联合奖励骤降，产生严重负 TD 误差，反而惩罚了本可解锁全局最优的探索行为，使系统被锁死在次优状态。
- **现有方案局限**：WQMIX、QPLEX 等改的是**混合网络结构/表示能力**，但并未解决经验采集阶段的行为病理；MADPO、MAVEN、LAIES、CDS 等要么引入辅助模型/内在奖励等结构开销，要么仍是**全体同时探索**。
- **论文含义**：AnP 提出一种**正交、即插即用**的补救思路——不在梯度更新或网络结构上做文章，而是在**数据生成（rollout）阶段**解耦探索方差与协调流形稳定性。

## 2. 方法论

### 核心思想
将 N 个智能体划分为两个集合：
- **扰动集 A_pert**（|A_pert| = M）：注入局部化、非对称的探索脉冲并退火；
- **锚定集 A_anch**（N − M 个）：严格保持名义贪心利用，构造"静止经验背景"。

这样任何后续信用分配都与队友非平稳性解耦，避免对称探索碰撞带来的灾难性 TD 惩罚。

### 关键技术细节

**（1）Anchor（锚定）**
- 定义：在时刻 t₀ 识别懒惰智能体坐标，同时冻结其余队友的操作流形。
- **不破坏 CTDE**：联合转移 P(s′|s,u) 与奖励 r(s,u) 仍由完整联合动作 u = (u_pert, u_anch) 决定；锚定只作用于**行为 rollout 接口**，两个集合的网络权重都保持动态更新并参与集中式梯度回传。
- 锚定集执行贪心：u_j = argmax_u Q_j(τ_j, u)，∀j ∈ A_anch。

**（2）懒惰智能体诊断指标（三条遥测信号）**
- *探索与策略萎缩*：滑动窗口 W 内的动作分布熵均值 H̄_i(t) 过早塌缩（H̄_i < δ_H）。
- *边际贡献不对称*：滚动边际贡献 c_i(t) ≪ (1/N)Σ_j c_j(t)。
- *联合回报停滞*：团队评估回报移动平均持续平台化且低于近优基线。
- 综合为**懒惰差异指数**：
  L_i(t) = [1 − c_i(t) / (max_j c_j(t) + ε₀)] · exp(−β·H̄_i(t))
- 干预时刻选择差异最大的坐标：A_pert = { argmax_i L_i(t₀) }。
- 论文还提出**自动化触发**的设想（在线事件驱动检测 + LLM 元监督，限制在 K+1 次推理调用内），但明确表示这部分是"正在研究"，并非本文已完成内容。

**（3）Perturb（扰动）**
- 扰动智能体采用局部循环退火调度：
  ε_t^(i) = ε_min + (ε_boost − ε_min) · max(0, 1 − (t − t₀)/T_anneal)
- 即先用较高探索率 ε_boost 探索，再在 T_anneal 窗口内退火至基线 ε_min，在静止队友背景下通过 TD 更新巩固新发现的高价值动作。
- 可迭代 K 个探索周期；**本文仅做最小 rank-1 单周期设定：M = 1, K = 1**，因此多智能体碰撞概率恒为 0。

## 6. 主要结论与发现

- **探索隔离有效**：向单一坐标（M=1）注入局部探索方差，可避免对称 M=N 再探索固有的奖励崩溃；锚定队友成功缓冲了团队的操作流形。
- **信用分配解耦**：被锚定的静止背景使扰动坐标新发现的高价值动作能被混合网络干净地强化。
- **修复能力**：从胜率 5%、回报 7.48 的崩溃低谷，经一次扰动退火后恢复到 85% 胜率（回报 18.01），此后到 3,000 episode 维持 40%–50% 平均胜率。
- **逃逸能力**：在平台期干预后，脉冲尾部达到峰值 90% 胜率（回报 18.82）；扰动后巩固窗口（2,325–3,000 episode）中 78.6% 的检查点胜率 ≥ 60%，评估回报稳定在 15.5–17.5。
- **总体主张**：AnP 是一种**无需修改网络结构**、轻量、正交的协调失败补救方案。

## 7. 优点

- **切入角度新颖且正交**：把问题从"改网络/改损失"转移到"改 rollout 行为"，绕开了单调性约束与非单调奖励空间的结构性瓶颈，理论上与现有值分解方法解耦、易组合。
- **诊断指标可量化**：把"懒惰智能体"这一偏定性的概念形式化为可追踪的遥测指标（熵塌缩、边际贡献偏斜、回报停滞）并凝练为显式的 L_i(t) 准则，为后续自动化触发提供了数学接口。

- **对比设计有理论针对性**：作者清楚说明为何对称 ε 增量无法解决问题（非单调地形 + 负 TD 误差惩罚探索），并在未来工作中设计了 M=N 与随机坐标两组关键消融，方向明确。
