## 摘要
合作涌现是多智能体系统中的一个核心问题，因为去中心化智能体必须在适应他人不断变化的行为的同时进行协调。演化博弈论识别出策略上稳定的结果，但在种群调整动态下的稳定性并不必然意味着有限样本学习智能体能够通过局部奖励反馈达到相同结果。我们在一个透明的、以治理为动机的三智能体博弈中研究这一区别，该博弈涉及政府、平台企业和用户。我们针对固定的阶段博弈激励推导复制子动态，在对称初始条件网格上评估合作演化吸引域，并将其与三种去中心化基于价值的学习器的学习吸引域估计进行比较。学习分析使用独立 Q 学习，分别采用 ε-贪心动作选择、缩放 Boltzmann 探索和 SA--EA BQL，在相同的收益环境和结果准则下进行。演化吸引域在采样网格上的体积为 V_E=1.00。经验学习吸引域对于 ε-IQL 为 0.88，而对于缩放 Boltzmann 和 SA--EA BQL 均为 0.00。诊断轨迹表明，在这种固定配置下，更广泛的动作多样性和非零价值分离可以与无法维持合作联合动作并存。这些结果表明，演化稳定性和学习可达性是耦合博弈--学习系统的不同性质。共享单车场景是一个激励性应用；更广泛的贡献是提供了一个框架，用于在指定的多智能体学习动力学下，比较种群层面的稳定性与合作的有限样本可达性。

## Abstract
Cooperation emergence is a central problem in multi-agent systems because decentralized agents must coordinate while adapting to the changing behavior of others. Evolutionary game theory identifies strategically stable outcomes, but stability under a population adjustment dynamic need not imply that finite-sample learning agents can reach the same outcome through local reward feedback.   We study this distinction in a transparent three-agent governance-motivated game involving a government, a platform firm, and users. We derive replicator dynamics for the fixed stage-game incentives, evaluate the cooperative evolutionary basin on a symmetric initial-condition grid, and compare it with learning-basin estimates for three decentralized value-based learners. The learning analysis uses independent Q-learning with $\varepsilon$-greedy action selection, scaled Boltzmann exploration, and SA--EA BQL under the same payoff environment and outcome criterion.   The evolutionary basin has volume $V_E=1.00$ on the sampled grid. The empirical learning basin is $0.88$ for $\varepsilon$-IQL and $0.00$ for both scaled Boltzmann and SA--EA BQL. Diagnostic traces show that broader action diversity and nonzero value separation can coexist with failure to sustain the cooperative joint action in this fixed configuration.   These results indicate that evolutionary stability and learning accessibility are distinct properties of a coupled game--learning system. The shared-bike setting is a motivating application; the broader contribution is a framework for comparing population-level stability with the finite-sample accessibility of cooperation under specified multi-agent learning dynamics.

## 1. 核心问题与整体含义

- **研究动机**：合作涌现是多智能体系统的核心难题。去中心化智能体必须在适应他人不断变化行为的同时完成协调，因此"指定一个理想的集体结果"与"系统能否通过去中心化过程发现并维持该结果"是两件不同的事。
- **核心问题**：演化博弈论（ESS、复制子动力学）能识别策略上稳定的结果，但**种群调整动态下的稳定性是否意味着有限样本、仅依赖局部奖励反馈的学习智能体能到达同一结果？**
- **研究缺口**：演化稳定性常被当作"合作应当涌现"的直觉代理指标，但它并未规定学习规则、有限时域、初始化方式与结果判定准则；反之，一次成功的学习运行也不能证明该结果在种群层面稳定。两种分析的状态变量、信息流与随机性来源都不同，不能互相替代。
- **整体含义**：论文主张"演化稳定性"与"学习可达性"是**耦合博弈–学习系统的两种不同属性**，合作评估需要同时报告两者。共享单车后补贴治理（政府监管、平台合规、用户响应）只是动机性应用，真正的贡献是比较种群层稳定性与指定 MARL 动力学下合作有限样本可达性的框架。

### 2.4 MARL 学习动力学（三种去中心化价值学习器）

- **环境**：实现与表 1 完全相同的重复阶段博弈，无奖励塑形、无协调奖励、无收益改动；静态盆地实验固定于有利补贴状态（δ = 1）。
- **独立 Q 学习（IQL）**：每个智能体维护 Qᵢ(aᵢ)，把其他智能体动作视为环境的一部分；重复阶段更新为
  Qᵢ,ₜ₊₁(aᵢ,ₜ) = Qᵢ,ₜ(aᵢ,ₜ) + ηₜ[rᵢ,ₜ − Qᵢ,ₜ(aᵢ,ₜ)]，未选动作不更新，**不含延续价值项**。
- **ε-贪心 IQL**：以配置的探索概率随机选动作，否则选当前最高价值动作（透明基线，非优化策略）。
- **缩放 Boltzmann**：Prᵢ(a|s) = exp(Qᵢ(s,a)/[τᵢdᵢ]) / Σₐ′ exp(Qᵢ(s,a′)/[τᵢdᵢ])，其中 dᵢ 为收益尺度归一化，使三主体收益量级不同时 softmax 响应仍可解释。
- **SA–EA BQL（自适应探索变体）**：在缩放 Boltzmann 基础上令温度依赖 Q 值间隙，τᵢ = τ₀,ᵢ + kᵢΔQᵢ，用于检验自适应探索是否改变学习可达性。
- **机制诊断量**：动作覆盖率（少数动作比例）、策略熵（探索多样性）、Q 值分离（价值区分度）。

## 6. 主要结论与发现

- **演化盆地**：在 α = 80 的激励开启设定下，9 个冻结对称初值全部收敛至合作角点，V_E = 1.00（仅限采样网格）。
- **学习盆地分化**：
  - ε-贪心 IQL：450 次中 396 次成功，学习盆地 0.880，bootstrap 95% CI [0.849, 0.909]，记录的"临界偏好"为 p = 0.1；
  - 缩放 Boltzmann：450 次中 0 次成功，学习盆地 0.000；
  - SA–EA BQL：450 次中 0 次成功，学习盆地 0.000。
- **核心发现**：在固定收益环境下，**演化收敛并不保证每一种去中心化学习规则都能到达同一合作结果**；演化稳定性与学习可达性是耦合博弈–学习系统的不同性质，稳定合作状态在有限样本去中心化适应中表现出学习机制依赖性。
- **机制诊断**：Boltzmann 类学习器保留了更高的动作多样性（少数动作比例、终端策略熵）且 Q 值间隙非零，因此零盆地**不能简单归因于探索不足或过早坍缩为确定性策略**；更审慎的解释是，持续随机动作选择可能反复打断那个本可强化合作价值的联合动作剖面，从而阻碍"惯例"（convention）形成——即**探索多样性 ≠ 协调承诺**，动作覆盖率高不等于学会兼容策略。
- **实践启示**：均衡分析只是评估激励结构的不完整依据；机制设计与学习设计应联合考虑；学习可达性应作为报告维度而非事后解释；主张合作行为时必须声明其成立的调整过程。

## 7. 优点

- **问题设定清晰且有价值**：把"策略稳定性"与"学习可达性"明确区分，并给出可操作的度量 A_L(M)，填补了演化博弈与 MARL 之间常被默认跨越的推理缺口。
- **受控比较设计**：在**完全相同的收益环境、初值网格与结果准则**下并列两种动力学，避免环境变化混淆机制差异；这是本文方法论上最扎实的部分。
- **诊断而非归因于算法优劣**：通过动作覆盖率、策略熵、Q 值分离三组诊断，排除"探索不足/过早确定性坍缩"这一最直观解释，得出"多样性不等于协调"的更细致结论。

- **可复现性意识**：提供了算法流程（Algorithm 1）、固定协议表与演化方程推导附录，明确区分"配置记录"与"额外假设"。

- **零盆地结果的解释力有限**：两个学习器 450 次全部失败是强结论，但作者明确表示未识别唯一因果机制，

而收益尺度、更新轨迹、早期联合动作历史与价值归一化形式都可能是共同作用因素；作者只能提出"探索多样性破坏惯例形成"作为候选解释，尚缺乏干预实验（如冻结探索、加入承诺机制、改变早期历史）来确证或排除。

- **合作结果判定准则的敏感性未检验**：学习盆地依赖于"预设合作结果判定准则"，但该准则的具体形式与阈值未在正文披露，也未做替代准则（如时间平均策略、最后一次动作、价值收敛判据）下的稳健性对照。鉴于两个学习器在 450 次运行中全数失败，判定准则的严格程度对结论有实质影响。
- **对称初值的设计约束**：所有初值均取 (p,p,p) 的对称形式，且仅在首个决策施加，这意味着实验并未覆盖"部分主体已接近合作、部分远离"这类非对称起始配置，而现实治理中三方往往处于不同初始状态。
- **重复阶段博弈的设定限制**：环境是无状态（stateless）的重复阶段博弈，因而本文关于"学习可达性"的结论不能被直接外推到存在状态转移、部分可观测、信用分配更复杂的 MARL 场景；作者本人也未做此声称，但读者容易误推。
- **缺少与集中式/通信式方法的对照**：论文只比较三种去中心化价值学习器，未纳入集中训练分散执行、参数共享或允许通信的基线，因此无法回答"若加入协调信息通道，零盆地是否可被打开"这一设计层面的关键问题。

## 9. 可复现性与透明度

- 论文提供了算法流程（Algorithm 1）、固定协议表与复制子方程推导，结构上具备复现骨架。
- 但正文以"冻结配置"指代关键超参数（学习率 η、温度 τᵢ、尺度因子 dᵢ、系数 kᵢ、合作判定准则），未给出具体数值；亦未提及代码、数据或配置文件的公开可得性声明。
- 因此**概念性结论可被独立检验，数值性结论的精确复现存在障碍**；后续工作若要在此基础上比较，需要作者补充完整配置清单。

## 10. 开放问题与未来方向

- **理论方向**：给出"博弈结构性质 × 学习更新性质"对齐的可判定条件，说明何时演化稳定结果同时是某类去中心化学习器可达的，何时不是。
- **实证方向**：开展超参数与探索调度扫描、非对称初值与异质主体实验、更大种群与网络拓扑实验、有状态环境实验，以界定结论的边界。
- **设计方向**：把"学习可达性"从评估维度提升为机制设计约束——例如通过调整激励强度、引入可观测信号或轻量通信，使稳定结果同时成为可学习的惯例。
- **报告规范方向**：推动在合作涌现类研究中同时报告种群层稳定性与指定学习动力学下的有限样本可达性，避免用其中之一替代另一者。

## 11. 总体评价

- 本文的核心价值在**概念澄清与方法论示范**，而非算法创新：它用一个透明、可完全控制收益结构的治理博弈，构造出"演化盆地满格、学习盆地为零"的干净反例，说明稳定性与可达性之间的推理跳跃并不安全。
- 其证据强度在"固定配置、有限样本"的意义上是可靠的，但在"普适性、因果机制、稳健性"三个维度上均被作者主动限定，读者应据此调整引用范围。
- 对多智能体系统与去中心化治理研究者而言，最实用的启示是：**报告合作涌现结论时，必须同时声明调整过程（演化动态还是具体学习规则）、样本规模与结果判定准则**；均衡分析只能回答"激励是否值得追求"，不能回答"系统能否学会追求"。

（完）
