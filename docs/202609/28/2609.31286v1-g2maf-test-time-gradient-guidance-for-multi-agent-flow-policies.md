## 摘要
离线多智能体强化学习（MARL）从固定数据集中学习协作策略，无需进一步与环境交互，且学习到的策略在部署时被冻结。这种冻结策略通常在部署时仅提出一个联合动作并直接执行。然而，这种一次性部署往往会固守一个次优提议，即便存在与行为数据一致的更优邻近备选方案。为解决该问题，我们提出了梯度引导多智能体流（G2MAF），一种用于在测试时优化联合策略的精化框架。G2MAF 应用一个全局归一化、投影后的评论家梯度来引导并协调所有智能体的修正，同时使动作既可行又贴近冻结策略的提议。在 24 个 MPE 和 SMAC 设置中，其标准变体改进了 20 个冻结设置，在 MPE 上平均相对增益为 9.2%，在 SMAC 上为 8.9%，而模型推理延迟仅增加约 6%。

## Abstract
Offline multi-agent reinforcement learning (MARL) learns cooperative policies from fixed datasets without further environment interaction and a learned policy is frozen at deployment. Such a frozen policy typically proposes a single joint action and executes it directly at deployment time. However, this one-shot deployment often commits to a suboptimal proposal, even when better nearby alternatives remain consistent with the behavior data. To address this issue, we propose Gradient Guided Multi Agent Flow (G2MAF), a refinement framework for optimizing joint policies at test-time. G2MAF applies one globally normalized, projected critic gradient to guide and coordinate all agents' corrections while keeping the action both feasible and close to the frozen policy proposal. Across 24 MPE and SMAC settings, its canonical variant improves 20 frozen settings, with mean relative gains of 9.2% on MPE and 8.9% on SMAC, with model inference latency increased by about 6% only.

## 二、方法论

### 2.1 核心思想

- 冻结的生成式联合策略 π_θ 提供"行为数据支持范围内"的起点 a_θ；冻结的集中式行为评论家 Q_φ 提供一次**全局归一化、投影后的联合梯度**，把整个联合动作向量朝更高团队价值方向推一小步，同时保持动作可行、且贴近原提议。
- 理论落点：对 KL 正则化的局部策略改进目标
  - `max_{π≪π_θ} E_{a∼π}[Q_φ(o,a)] − β·KL(π ‖ π_θ)`
  - 其解为"价值倾斜分布" `π_Q(a|o,g) ∝ π_θ(a|o,g)·exp(Q_φ(o,a)/β)`，连续密度下对应得分函数 `∇_a log π_Q = ∇_a log π_θ + β⁻¹∇_a Q_φ`。
  - 由于生成骨干是隐式 push-forward，无法直接算该得分，故**只取价值梯度项**，对一次采样得到的可执行联合动作做一步精化。

### 2.2 关键技术细节

- **冻结生成骨干（CGB / CoFlow）**：少步（K=5）流匹配生成归一化联合观测轨迹，流匹配目标 `L_flow = E‖u_ϑ(z_α,0,α;c) − (z₁−x₀)‖²`；跨智能体注意力（Coordinated Velocity Attention, CVA）使速度场是联合函数而非各智能体独立流；共享逆动力学头解码出动作 a_θ。
- **冻结集中式评论家**：一步 FQE / TD 回归 `y = r + γc·Q̄(o′,a′)`，4 层 MLP、每层 512 单元、LayerNorm + SiLU，20k 步 TD 训练，γ=0.99，目标网络软更新 τ=0.005；离散域输入拼接各智能体 one-hot。因为接收完整联合观测-动作，`∇_{a_i}Q_φ` 依赖所有队友动作，天然给出协调修正。
- **连续动作更新（标准 / canonical 变体）**：
  - `ã = Π_A( a_θ + η · ∇_a Q_φ(o,a_θ) / (‖∇_a Q_φ(o,a_θ)‖₂ + ε) )`，ε=10⁻⁶。
  - 梯度在**完整联合向量上拼接后再归一化**（而非逐智能体归一化），因此团队只获得"一份修正预算"，同时保留评论家对不同智能体修正量的相对分配。
- **理论保证**：把问题写成信赖域 `s* = argmax_{‖s‖₂≤η} ⟨d_θ, s⟩ = η·d_θ/‖d_θ‖₂`；因投影非扩张，`‖ã − a_θ‖₂ ≤ η`；对投影变分不等式得 `⟨d_θ, s⟩ ≥ (D_ε/η)‖s‖²`；若 Q_φ 沿线段 L-Lipschitz 光滑，则
  - `Q_φ(o,ã) − Q_φ(o,a_θ) ≥ (D_ε/η − L/2)‖s‖²`，
  - 故 `0 < η < 2D_ε/L` 时，任何非零投影更新都**严格提升集中式评论家值**；在局部评论家一致性与支持保持条件下，同量缩小逐样本协调间隙。
- **价值信号注入位置（三种变体）**：
  - **All**：每个反向 Euler 流步后都注入（经解码器 Jacobian 的链式法则把评论家梯度传回轨迹空间，需在归一化坐标下另训评论家 Q^norm）。
  - **Final**：只在最后一步注入。
  - **Post**：流完成后解码出 a_θ，直接在可执行动作空间做一次更新（论文实际部署选择，复用行为评论家）。
  - 因解码器非线性，轨迹空间编辑与动作空间编辑**一般不等价**。
- **离散动作（SMAC）**：对合法动作掩码后 softmax 松弛 `p_i = softmax(ℓ_i + log m_i)`，`d_ℓ = ∇_ℓ Q_φ(o,p)`，`ℓ̃ = ℓ + η·d_ℓ/(‖d_ℓ‖+ε)`，再重新掩码后 `ã_i = argmax_j{ℓ̃_{ij} + log m_{ij}}`；步长在 logit 空间尺度更大（动作只在竞争 logit 交叉时改变）。
- **超参数**：唯一超参是步长 η；连续 η ∈ [0.01, 0.1]（单位归一化梯度），离散 η ∈ [2, 50]；每次决策只做一次评论家反向传播，无 actor 更新、无候选搜索、无模型 rollout。
