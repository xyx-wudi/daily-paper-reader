## 摘要
开放智能体系统（OASYS）在现实领域日益普遍，其中智能体和任务集合会随时间不可预测地变化。这种开放性，包括智能体开放性（AO）和任务开放性（TO），对通常假设固定状态和动作空间的多智能体强化学习（MARL）构成了根本性挑战。现有方法仅部分解决了开放性问题：填充和掩码方法引入了人为界限，而最近的基于图或超图的方法处理了开放性的一维，但仍依赖于限制性假设。在本文中，我们提出了面向智能体和任务开放性的指针学习器（PLATO），这是一种基于指针网络的行动者结合集中式图神经网络（GNN）评论家，采用集中训练与分散执行范式下的多智能体近端策略优化进行训练。我们的基于指针的行动者直接在当前任务集上输出分布。这直接支持了动作空间的变化，无需掩码或重新训练。我们的GNN评论家将智能体-任务交互编码为一个随任务和智能体组成变化形状的图。这些组件共同考虑了AO和TO，而没有现有方法的有界性。我们在任务与智能体开放马尔可夫博弈（TaAgO-MG）中形式化了PLATO，扩展了先前的任务开放形式化，并证明了它在产生的无界状态和动作空间上是良定义的。我们使用开放智能体系统评估方法倡议（MOASEI）的野火抑制领域评估了PLATO，该环境是为开放多智能体系统评估而设计的，我们展示了在OASYS中，PLATO相比最先进的基线具有更强的性能和更一致的零样本泛化能力。

## Abstract
Open agent systems (OASYS) are increasingly prevalent in real-world domains where the sets of agents and tasks change unpredictably over time. Such openness, including agent openness (AO) and task openness (TO), poses a fundamental challenge to multi-agent reinforcement learning (MARL), which typically assumes fixed state and action spaces. Existing methods address openness only partially: padding and masking approaches introduce artificial bounds, while recent graph-based or hypergraph methods handle one dimension of openness but still depend on restrictive assumptions. In this paper, we introduce Pointer Learner for Agent and Task Openness (PLATO), a pointer-network-based actor combined with a centralized graph neural network (GNN) critic, trained with multi-agent proximal policy optimization under a centralized training and decentralized execution paradigm. Our pointer-based actor outputs distributions directly over the current task set. This directly supports changing action spaces without masking or retraining. Our GNN critic encodes agent-task interactions as a graph that changes shape with task and agent composition. Together, these components consider AO and TO without the boundedness of existing approaches. We formalize PLATO in a Task-and-Agent-Open Markov Game (TaAgO-MG), extending prior task-open formulations, and prove it is well-defined over the resulting unbounded state and action spaces. We evaluate PLATO with the Methods for Open Agent Systems Evaluation Initiative (MOASEI) wildfire suppression domain, an environment designed for open multi-agent system evaluation, and we demonstrate strong performance and more consistent zero-shot generalization than state-of-the-art baselines in OASYS.

- **整体含义**：本文提出首个能够**同时处理智能体开放性（AO）和任务开放性（TO）** 的MARL算法（PLATO），无需固定界限或重新训练，为开放环境下的多智能体决策提供了理论框架和实用方法。

## 2. 方法论

### 核心思想
- PLATO基于**集中式训练-分散式执行（CTDE）** 范式，采用：
  - **基于指针网络的行动者（Pointer Actor）**：通过内容导向的点选机制，直接在当前任务集上输出行动分布，支持任务集变化。
  - **集中式图神经网络评论家（GNN Critic）**：将全局状态编码为二部图（智能体-任务），图结构随系统组成动态变化，支持智能体数量变化。
- 使用**多智能体近端策略优化（MAPPO）** 进行联合训练。

### 关键技术细节
- **指针行动者**流程（每个智能体）：
  1. 预处理：将局部观察分解为智能体特征矩阵和任务特征矩阵。
  2. 编码查询（Query）：基于所有智能体特征统计量（均值、方差、最小、最大）生成固定维度的查询向量。
  3. 编码键（Key）：为每个当前任务生成一个键（包括一个NO-OP键）。
  4. 指针解码：通过加法注意力（Additive Attention）计算查询与每个键的匹配得分，经Softmax得到当前任务集上的行动分布。
- **GNN评论家**：
  1. 构建二部图：节点为智能体和任务，边为所有智能体-任务对。
  2. 节点嵌入：分别用MLP编码智能体和任务特征，拼接后得到初始节点嵌入。
  3. 图卷积（2层GCN）：在二部图上进行消息传递，并加入残差连接。
  4. 池化与输出：对所有节点嵌入取平均，再通过MLP映射为标量价值。
- **训练损失**：PPO裁剪目标（行动者）+ 价值回归损失（评论家），使用广义优势估计（GAE）。
- **形式化框架**：扩展了任务开放马尔可夫博弈（TaO-MG）为**任务与智能体开放马尔可夫博弈（TaAgO-MG）**，并证明了PLATO在无界状态和动作空间上的良定义性（well-defined）和置换不变性（permutation invariance）。

## 3. 实验设计

- **环境与场景**：使用**MOASEI野火抑制领域**（MOASEI Wildfire），在2×3、3×3、4×4三种网格上进行实验。每个网格中消防员智能体固定位置，使用有限的灭火剂扑灭随机生成的火焰（任务）。内生TO（火势蔓延）、外生TO（随机火灾生发）和AO（灭火剂耗尽后退出补给）均被模拟。
- **四种设置（Setups）**：
  - S0：封闭基线（无火势蔓延、无随机火灾、无限灭火剂）。
  - S1：内生TO（蔓延概率0.6）+ AO（补给成功概率1.0）。
  - S2：外生TO（随机火灾概率0.6）+ AO（补给成功概率0.8）。
  - S3：两者结合（蔓延+随机火灾，补给成功概率0.6），最困难。
- **对比方法**：
  - **智能基线**：DGN（图卷积强化学习）、DICG（深度隐式协调图）、MOHITO（超图MARL，专为TO设计）。
  - **启发式基线**：NO-OP（始终不行动）、Random（均匀随机）、Weakest（优先扑灭最弱火）、Strongest（优先扑灭最强火）。
- **评估指标**：**性能**（回合回报）、**效率**（每场战斗的平均奖励）、零样本泛化（在不同尺寸网格上测试，不重新训练）。统计分析采用Bonferroni校正的Shapiro-Wilk自适应双尾检验（α=0.05/方法数）。

## 4. 资源与算力

- **执行环境**：实验在高性能计算集群上完成，节点为Linux 64位架构，双路Intel Xeon Gold 6348 CPU（共56核），仅使用CPU，未使用GPU。
- **训练时长**：每个单独的训练运行（一个方法、一个网格、一个设置）约需**3-5天CPU时间**。
- **总计算量**：全部实验（包括所有方法、网格、设置以及Optuna超参搜索（每方法50个试验））共计约**6000-10000 CPU天**。

## 5. 实验数量与充分性

- **实验数量**：
  - 三种网格尺寸 × 四种设置 × 八种方法（PLATO及7个基线）+ 零样本泛化（两种训练网格 → 两种/三种测试网格）。
  - 消融实验：4种PLATO变体（MLP/LSTM编码器 × 加法/点积注意力），在原生和零样本设置下均进行了评估。
  - 每次评估使用150个测试回合（50种子 × 3个检查点）。
- **充分性与公平性**：
  - 所有方法使用**Optuna超参调优**（每个方法50个试验），优化目标相同（3×3网格S3设置下的验证回报），确保基线在公平条件下得到最优配置。
  - 采用**严格的三级种子协议**（全局种子、训练种子、执行种子），固定执行种子使不同方法在相同随机条件下对比，减少方差。
  - 统计检验采用Bonferroni校正，控制多重比较错误率。
  - 实验覆盖了从封闭到高度开放的不同条件，以及零样本泛化到未见过网格的情况，**充分验证了方法的鲁棒性和泛化能力**。

## 6. 主要结论与发现

- **性能表现**：PLATO在大多数开放设置下（S1-S3）获得**统计上显著的最高回合回报**，尤其在S2（外生TO）和S3（联合开放）中大比分领先，且优势在更大网格（4×4）下更加明显。
- **效率**：PLATO的每场战斗奖励在多数设置下为正值且最高，表明其行动更高效。
- **零样本泛化**：PLATO在零样本转移到更大网格时表现出**最一致的强性能**，在S2和S3设置下显著优于基线，而MOHITO等基线在某些组合下出现负回报或退化。
- **消融分析**：
  - LSTM编码器 + 加法注意力（lstm+add）在联合开放零样本场景下表现最佳。
  - MLP + 点积注意力（mlp+dot）在封闭零样本场景下表现最佳。
  - 没有一种变体在所有情况下绝对占优，说明编码器与注意力机制的选择与环境开放程度相关。

## 7. 优点

- **理论贡献**：首次给出同时处理AO和TO的MARL形式化框架（TaAgO-MG），并证明了算法在无界空间上的良定义性和置换不变性。
- **方法创新**：指针网络实现变尺度动作输出，避免了固定索引、掩码或再训练；GNN评论家自然支持变数量的智能体和任务。
- **实验规范**：严格的超参调优、多重复制、Bonferroni校正统计检验、零样本泛化测试，实验设计客观、公平、充分。
- **实用性**：PLATO在多样化的开放动态下保持稳定，且零样本泛化能力强，适合实际开放环境部署。

## 8. 不足与局限

- **当前假设**：每个任务只有一个关联动作（如“扑灭某火”），不支持具有多动作的任务（例如操作不同类型设备），作者计划未来扩展。
- **全观测假设**：智能体局部观察假设能获取所有智能体和任务的特征（虽然受范围限制），未考虑部分可观测性，未来可研究扩展。
- **仅关注AO和TO**：未处理框架开放性（FO，即智能体内部目标、偏好变化），留给未来工作。
- **计算量较大**：虽然PLATO的复杂度为O(|N|² + |N||X|)，但全实验依赖大量CPU计算，可能与GPU加速不兼容。
- **仅在一个领域（野火抑制）上验证**：虽然符合MOASEI标准，但泛化到其他开放多智能体领域（如交通控制、机器人集群）仍需进一步验证。
