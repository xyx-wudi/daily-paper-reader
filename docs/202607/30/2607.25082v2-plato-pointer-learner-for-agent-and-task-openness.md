## 摘要
开放智能体系统（OASYS）在现实世界中日益普遍，其中智能体和任务集合随时间不可预测地变化。这种开放性，包括智能体开放性（AO）和任务开放性（TO），对通常假设固定状态和动作空间的多智能体强化学习（MARL）构成了根本性挑战。现有方法仅部分解决了开放性问题：填充和掩码方法引入了人为边界，而最近的基于图或超图的方法处理了单一维度的开放性，但仍依赖于限制性假设。在本文中，我们引入了面向智能体与任务开放性的指针学习器（PLATO），一种基于指针网络的actor与集中式图神经网络（GNN）critic相结合的方法，在集中式训练与分散式执行范式下使用多智能体近端策略优化进行训练。我们的基于指针的actor直接在当前任务集合上输出分布，这直接支持了无需掩码或重新训练的动作空间变化。我们的GNN critic将智能体-任务交互编码为随任务和智能体组成而改变形状的图。这些组件共同考虑了智能体开放性和任务开放性，而不受现有方法的有界性限制。我们在任务与智能体开放马尔可夫博弈（TaAgO-MG）中形式化了PLATO，扩展了先前的任务开放公式，并证明其在产生的无界状态和动作空间上是良定义的。我们使用开放智能体系统评估方法倡议（MOASEI）的野火抑制领域对PLATO进行了评估，该环境专为开放多智能体系统评估而设计，并且我们展示了相比OASYS中最先进的基线更强的性能和更一致的零样本泛化能力。

## Abstract
Open agent systems (OASYS) are increasingly prevalent in real-world domains where the sets of agents and tasks change unpredictably over time. Such openness, including agent openness (AO) and task openness (TO), poses a fundamental challenge to multi-agent reinforcement learning (MARL), which typically assumes fixed state and action spaces. Existing methods address openness only partially: padding and masking approaches introduce artificial bounds, while recent graph-based or hypergraph methods handle one dimension of openness but still depend on restrictive assumptions. In this paper, we introduce Pointer Learner for Agent and Task Openness (PLATO), a pointer-network-based actor combined with a centralized graph neural network (GNN) critic, trained with multi-agent proximal policy optimization under a centralized training and decentralized execution paradigm. Our pointer-based actor outputs distributions directly over the current task set. This directly supports changing action spaces without masking or retraining. Our GNN critic encodes agent-task interactions as a graph that changes shape with task and agent composition. Together, these components consider AO and TO without the boundedness of existing approaches. We formalize PLATO in a Task-and-Agent-Open Markov Game (TaAgO-MG), extending prior task-open formulations, and prove it is well-defined over the resulting unbounded state and action spaces. We evaluate PLATO with the Methods for Open Agent Systems Evaluation Initiative (MOASEI) wildfire suppression domain, an environment designed for open multi-agent system evaluation, and we demonstrate strong performance and more consistent zero-shot generalization than state-of-the-art baselines in OASYS.

## 1. 核心问题与整体含义（研究动机和背景）
- **问题**：多智能体系统的开放性（Agent Openness, AO 和 Task Openness, TO）导致智能体和任务集合动态变化，传统多智能体强化学习（MARL）假设固定状态和动作空间，无法直接应对这类场景。
- **背景**：现有方法（如填充/掩码、基于图或超图的方法）仅能部分处理开放性问题，要么引入人为边界，要么依赖限制性假设（如固定动作集、单一维度开放性）。
- **整体含义**：PLATO 旨在联合处理 AO 和 TO，在无需重训练或人工边界的情况下，使策略适应动态变化的智能体和任务集合，提升开放环境下的鲁棒性和泛化能力。

## 2. 方法论
- **核心思想**：结合指针网络（Pointer Network）的 actor 和图神经网络（GNN）的 critic，在集中式训练与分散式执行（CTDE）范式下，通过内容指向机制直接输出当前可用任务上的动作分布。
- **关键技术细节**：
  - **指针 Actor**：每个智能体根据本地观察分解为智能体特征矩阵和任务特征矩阵；通过聚合智能体统计量（均值、方差、最小、最大）得到固定长度查询向量；逐任务编码得到键向量；使用加法注意力计算查询与每个任务键的分数，通过 softmax 获得当前任务集上的策略（包含 NO-OP 动作）。支持任务集合大小变化，且对智能体顺序具有置换不变性。
  - **GNN Critic**：将全局状态建模为二部图（智能体节点和任务节点，边表示可行动作），使用图卷积网络（GCN）进行消息传递，通过均值池化和 MLP 输出标量状态值。图结构随 |N| 和 |X| 动态变化，避免固定大小的拼接。
  - **训练算法**：基于 MAPPO（多智能体近端策略优化），使用集中式 critic 和共享策略，采用 GAE 计算优势函数，PPO-clip 目标更新 actor 和 critic。
- **理论保证**：证明 actor 和 critic 在无界开放智能体-任务空间上是良定义的（permutation invariant），且引理证明了任务指针和智能体指针的支持自适应性和排名一致性。

## 3. 实验设计
- **场景与数据集**：使用 MOASEI（Methods for Open Agent Systems Evaluation Initiative）的 **WILDFIRE** 域（野火扑灭场景）。网格大小：2×3、3×3、4×4。智能体为消防员，任务为火灾。四种开放设置（S0–S3）：
  - S0：封闭无开放（无火蔓延、无随机点燃、无限灭火剂）
  - S1：内源任务开放（火蔓延概率 0.6，灭火剂无限）
  - S2：外源任务开放（随机点燃概率 0.6，灭火剂补充概率 0.8）
  - S3：任务开放 + 智能体开放（火蔓延 0.6，随机点燃 0.6，补充概率 0.6）
- **对比方法**：
  - 智能基线：DGN、DICG、MOHITO（均基于 MARL，但 DGN/DICG 假设固定智能体/任务，MOHITO 针对任务开放但忽略智能体开放）
  - 朴素基线：NOOP（始终不行动）、Random（均匀随机行动）、Weakest（优先压制最小火灾）、Strongest（优先压制最大火灾）
- **评估指标**：累计回合回报（Episode Return）、每次灭火行动的奖励（Reward per Fight）。此外统计了燃烧事件数、扑灭事件数、NOOP 比例等辅助指标。
- **训练/测试模式**：
  - 原生评估（Native）：训练和测试在同一网格上
  - 零样本泛化（Zero-shot）：训练在较小网格（2×3 或 3×3），测试在较大网格（3×3、4×4 或 5×5），不进行重训练
  - 消融实验：2（MLP vs LSTM 编码器）×2（加法注意力 vs 点积注意力）共 4 种变体

## 6. 主要结论与发现
- **性能**：PLATO 在 3×3 和 4×4 网格的开放设置（S2, S3）上获得最高的累计回报，且统计显著；在封闭设置（S0）上与其他智能基线持平。
- **效率**：PLATO 在多数开放设置下每灭火行动回报最高，表明更有效地利用灭火剂。
- **零样本泛化**：PLATO 在从较小网格到较大网格的零样本转移中表现最稳定，尤其在 S2（组合任务开放）下明显优于 DGN、MOHITO；DICG 在某些场景下也表现不错，但整体稳定性不及 PLATO。
- **消融**：LSTM 编码器 + 加法注意力（lstm+add）在组合开放（S3）零样本场景下表现最佳；MLP + 点积注意力在封闭零样本场景下表现更好。没有一种变体始终最优，说明编码器和评分函数的选择与开放程度相关。
- **复杂度**：PLATO 每个时间步的复杂度（actor+critic）为 O(|N|² + |N||X|)，与智能体和任务数量呈线性/二次关系，可接受。

## 7. 优点
- **方法创新**：首次联合处理 AO 和 TO，无需人工边界或重训练，通过内容指向机制直接适应动态任务集和智能体集。
- **理论严谨**：形式化定义了 TaAgO-MG，并证明了 actor 和 critic 的置换不变性和良定义性，引理说明了指针策略如何对开放变化自适应。
- **实验全面**：覆盖多种网格大小、多种开放设置、零样本泛化和详尽的消融，统计检验严格。
- **实用性强**：在 MOASEI 标准域上验证，代码公开，超参调优公平对比。

## 8. 不足与局限
- **当前 TaAgO-MG 限制**：假设每个任务只有一个关联动作（如 suppress），未能支持多动作任务（如同时扑救一个火灾的多个子动作），论文计划未来扩展。
- **完全可观察性假设**：actor 和 critic 均依赖智能体对任务和其他智能体的完全观察，未考虑局部可观察或不确定性的实际场景。
- **未处理帧开放（Frame Openness, FO）**：论文仅处理 AO 和 TO，未考虑智能体内部配置（目标、偏好、能力）的变化，这在实际系统中也很关键。
- **实验环境单一**：仅使用 Wildfire 域，未能展示在其他开放域（如交通控制、多机器人搜索）上的泛化能力。
- **计算资源较高**：CPU 训练耗时较长，可能限制大规模快速迭代；未利用 GPU 加速也是一个潜在效率改进点。
- **零样本泛化不稳定**：在某些从 2×3 到 4×4 的转移设置（如 S3）下，PLATO 的回报方差较大，表明对极端开放尺度变化尚不如 DICG 鲁棒。
