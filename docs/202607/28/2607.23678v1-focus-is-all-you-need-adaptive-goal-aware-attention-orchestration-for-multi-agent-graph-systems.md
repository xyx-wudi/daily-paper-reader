## 摘要
大型语言模型（LLM）使自主智能体能够进行推理、规划和工具使用。最近的系统越来越多地将这些智能体组织为专门化、互联节点的图。尽管基于图的编排支持灵活的分解和协调，但它产生了一个关键挑战：**注意力分配**。随着工作流的增长，现有方法通常均匀地执行图组件，在无关或低影响任务上浪费资源。我们引入**注意力编排**（Attention Orchestration）范式，将Transformer风格的注意力从token表示扩展到工作流级别的智能体协调。我们的框架**自适应目标感知注意力编排（AGAO）**基于用户目标、图依赖和计算约束动态估计智能体重要性。AGAO结合三个组件：(1) 目标感知注意力，衡量用户目标与智能体能力之间的语义相关性；(2) 拓扑感知注意力，建模智能体图中的结构依赖关系；(3) 资源感知注意力，跨异构智能体分配预算和执行优先级。这些机制共同将静态智能体图转变为自适应系统，将计算聚焦于目标关键推理路径。在多种多智能体工作负载上的实验表明，与现有基于图的执行策略相比，AGAO提高了任务有效性，同时减少了不必要的计算、延迟和令牌消耗。我们的工作将**注意力工程**（Attention Engineering）作为可扩展、智能多智能体系统的方向。代码：https://github.com/MingzhouFan97/AGAO。

## Abstract
Large language models (LLMs) enable autonomous agents for reasoning, planning, and tool use. Recent systems increasingly organize these agents as graphs of specialized, interconnected nodes. Although graph-based orchestration supports flexible decomposition and coordination, it creates a key challenge: \textbf{attention allocation}. As workflows grow, existing approaches often execute graph components uniformly, wasting resources on irrelevant or low-impact tasks. We introduce \textbf{Attention Orchestration}, a paradigm that extends Transformer-style attention from token representations to workflow-level agent coordination. Our framework, \textbf{Adaptive Goal-aware Attention Orchestration (AGAO)}, dynamically estimates agent importance based on user objectives, graph dependencies, and computational constraints. AGAO combines three components: (1) goal-aware attention, measuring semantic relevance between user goals and agent capabilities; (2) topology-aware attention, modeling structural dependencies in agent graphs; and (3) resource-aware attention, allocating budgets and execution priorities across heterogeneous agents. Together, these mechanisms transform static agent graphs into adaptive systems that focus computation on goal-critical reasoning paths. Experiments across diverse multi-agent workloads show that AGAO improves task effectiveness while reducing unnecessary computation, latency, and token consumption compared with existing graph-based execution strategies. Our work establishes \textbf{Attention Engineering} as a direction for scalable, intelligent multi-agent systems. Code: https://github.com/MingzhouFan97/AGAO.

## 2. 论文提出的方法论：核心思想、关键技术细节

- **核心思想**：提出 **AGAO（Adaptive Goal-aware Attention Orchestration）** 框架，在用户目标与智能体图执行之间引入一个注意力驱动的编排层。该层由三个互补的注意力模块组成，将智能体视为可动态选择的计算单元，而非固定工作流算子。
- **关键技术细节**：
  - **目标感知注意力（Goal-aware Attention）**：计算用户目标与每个智能体能力描述之间的语义对齐分数。将目标编码为查询向量 \(Q_g\)，智能体表示（能力描述、历史信息、状态）编码为键值对 \(K_i, V_i\)，通过缩放点积注意力得到归一化分数 \(\alpha_i^{\text{goal}}\)，表示智能体对当前目标的重要性。
  - **拓扑感知注意力（Topology-aware Attention）**：考虑图结构中依赖关系、路径重要性、中心性等。引入图偏置矩阵 \(B_G\) 到标准注意力计算中，得到图感知注意力分布 \(\alpha_i^{\text{topo}}\)，避免仅凭语义剪枝破坏必要执行路径。
  - **资源感知注意力（Resource-aware Attention）**：将综合注意力分数 \(\alpha_i^*\) 转化为实际的资源配置决策，包括模型路由（高分数用强模型）、token 预算分配（按指数比例分配）、执行优先级调度。
  - **自适应图路由（Adaptive Graph Routing）**：基于执行反馈（中间输出、状态、反馈信号）动态更新注意力状态 \(\alpha^{t+1} = \Phi(\alpha^t, o^t, G, q)\)，实现智能体在运行中进入、暂停或剪枝。算法流程见 Algorithm 1（文字描述）：初始化状态 → 编码目标 → 循环：计算目标注意 + 拓扑注意 → 融合 → 资源分配 → 激活分数阈值以上的智能体 → 执行 → 观察反馈 → 更新注意 → 更新状态 → 汇总输出。

## 3. 实验设计

- **任务与数据集**：
  - 8 个 **MBPP** 编程任务（Python 代码生成，评估 pass@1）
  - 8 个 **HotpotQA** 多跳问答任务（评估 token-level F1）
- **图结构**：每个任务使用手写的九节点图。编码图包含角色：需求分析、实现、测试、调试、审查、终稿等；问答图包含：分解、检索、证据选择、推理、验证、终稿等。
- **对比方法**（五种策略）：
  - **Random**：依赖有效的固定种子随机路由（每次最多选两个就绪节点）
  - **Static**：按固定图顺序执行所有依赖有效节点
  - **Semantic**：根据任务提示与节点能力描述的词汇重叠选取最多两个就绪节点
  - **MoE-style**：固定混合词汇相关性与拓扑分数，无反馈或自适应资源路由
  - **AGAO**：组合词汇目标相关性、拓扑分数、基于规则的反馈；可跳过低分节点，并在三个模型档次间路由
- **评估指标**：pass@1、F1、激活节点数、累计智能体时间、输入/输出 token 数。
