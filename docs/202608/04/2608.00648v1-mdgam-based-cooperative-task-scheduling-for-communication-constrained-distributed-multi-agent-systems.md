## 摘要
在通信受限的分布式多智能体系统中，协作任务调度具有挑战性，因为每个智能体必须在满足复杂实际约束的同时，根据部分且动态的观测做出决策。现有启发式方法依赖手工设计的投标规则和重复协商，而许多基于学习的方法假设全局观测，缺乏基于显式通信的协调。为解决这些局限性，本文提出了一种用于分布式多机器人任务分配（MRTA）的神经调度框架，由多解码器图注意力模型（MDGAM）策略模型和无评论家的分组相对多智能体策略梯度（GRMAPG）训练算法组成。MDGAM使用扩展的图注意力机制联合更新节点和边特征，并采用多个解码器生成任务选择决策和通信消息。GRMAPG从等价的任务规划实例中构造分组相对优势，以替代传统MARL算法中使用的评论家网络，从而降低训练难度并提高收敛性能。在不同问题规模和通信范围下的实验表明，所提方法在任务完成性能上优于现有的启发式和基于学习的方法，同时消融、复杂度和泛化测试进一步验证了所提出的创新。

## Abstract
Cooperative task scheduling in communication-constrained distributed multi-agent systems is challenging because each agent must make decisions from partial and dynamic observations while satisfying complex practical constraints. Existing heuristics rely on handcrafted bidding rules and repeated consensus, whereas many learning-based methods assume global observations and lack explicit communication-based coordination. To address these limitations, this paper proposes a neural scheduling framework for distributed multi-robot task allocation (MRTA), consisting of a multi-decoder graph attention model (MDGAM) policy model and a critic-free group relative multi-agent policy gradient (GRMAPG) training algorithm. MDGAM uses an extended graph attention mechanism to jointly update node and edge features, and employs multiple decoders to generate task-selection decisions and communication messages. GRMAPG constructs group-relative advantages from equivalent task-planning instances to replace the critic network used in conventional MARL algorithms, thereby reducing training difficulty and improving convergence performance. Experiments under different problem scales and communication ranges show that the proposed method improves task-completion performance over existing heuristic and learning-based methods, while ablation, complexity, and generalization tests further validate the proposed innovations.

### 1. 核心问题与整体含义（研究动机与背景）

- **问题背景**：分布式多智能体系统（如机器人、车辆、无人机）广泛应用于智能交通、物联网和应急响应等场景。在多机器人任务分配（MRTA）问题中，异构智能体需要在有限通信资源下协作完成空间分布的任务。
- **核心挑战**：
  - 每个智能体只能从**部分且时变的局部观测**中决策，无法获取全局信息；
  - 任务具有**时间窗口、服务时长、能力约束**，通信拓扑**随时间变化且可能分裂为多个不连通分量**；
  - 任务分配问题本质上是 NP-hard 的组合优化问题。
- **现有方法的不足**：
  - **启发式方法**（如 CBBA、PI-maxAss、EEPI）依赖手工设计的竞标规则和性能影响函数，需要反复协商与重规划，通信和计算开销大；
  - **学习方法**（如 DL-DRL、CAM）多假设全局观测，或缺乏显式通信协调机制，难以直接适用于通信受限的分布式场景。
- **本文目标**：构建一个神经网络调度框架，使各智能体在部分观测和有限通信条件下，通过显式通信协调与任务规划相结合，最大化总任务完成数。

- **编码器结构**：
  - 局部观测图包含当前智能体、其基地、候选任务节点、可达邻居智能体四类节点；边特征初始化为成对距离等；

- 在全部 9 组主实验中，**MDGAM+GRMAPG 的平均完成任务数均优于所有基线**。

### 7. 优点

- **方法创新性强**：将显式可学习的通信消息生成与任务决策融合在同一个神经网络中，弥补了传统学习方法缺乏通信协调的短板。
- **critic-free 训练机制设计巧妙**：利用任务规划问题固有的对称性（等价变换）构造组相对基线，避免了训练额外 critic 的复杂性和误差，是无偏且高效的策略梯度估计器，具有较好的理论可解释性。
- **架构可扩展且通用**：MDGAM 同时处理节点特征（智能体/任务）和边特征（距离/连通性），接口可接受更一般的转移成本输入，便于扩展到其他带约束的规划问题。
- **实验覆盖面较全**：主实验、消融、复杂度、泛化四个维度相互印证，结论较扎实；代码已公开，可复现性强。
- **针对实际部署考量**：提出基于事件驱动的异步局部决策流程，与单次贪心解码的测试策略一致，说明作者考虑了通信受限场景的实际约束。

### 8. 不足与局限

- **通信模型较抽象**：仅在拓扑层面建模通信（通信半径、连通分量、多跳可达），未显式建模带宽、时延、丢包、能量消耗等物理层因素。
- **静态任务集假设**：所有任务在任务开始前已知，未考虑在线任务到达、动态任务生成等更现实的动态场景。
- **训练成本较高**：在中等规模下即需 27 小时（4×RTX 3090），对于更大规模或更长训练周期可能成本过高。
- **泛化能力有限制**：智能体数变化较大（差 4）时性能下降约 3%；极端的通信范围（r=0.2 或 0.6）训练出的模型迁移到其他范围时性能损失较明显。
- **消融实验覆盖范围有限**：仅在一个规模上进行消融，且训练曲线对比仅一个设置；对不同硬件条件下运行时间对比的公平性没有展开讨论。
- **可扩展性隐忧**：通信成本随智能体数增长（当前设计会接收连通分量内所有消息），未来需进一步限制消息传播范围或降低消息维度以适配更严格的通信预算。
- **实验设置在应用导向上的说明不足**：如任务类型数固定为 2，对更多类型、更复杂异构场景的适应性尚未验证。
