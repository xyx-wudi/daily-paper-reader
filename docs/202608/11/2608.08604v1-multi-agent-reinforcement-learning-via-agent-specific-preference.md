## 摘要
多智能体强化学习（MARL）是解决复杂协作任务的强大框架，但它严重依赖于定义良好的全局奖励函数。设计此类奖励具有挑战性，尤其是在具有异构智能体的系统中，单一标量目标可能无法捕捉多样化的行为。在本文中，我们介绍了多智能体偏好整合学习（MAGPIE），通过智能体特定的偏好建模来应对这些挑战。每个智能体由专门的专家通过偏好信号进行评估，无需全局评估。我们从理论上证明，优化这些分散的偏好会收敛到纳什均衡策略。为了将局部偏好整合为连贯的全局目标，我们从偏好数据构建智能体特定的奖励模型，并通过单调聚合机制将它们组合。我们进一步证明，优化该聚合奖励模型等同于训练纳什均衡策略。在基准多智能体任务和顺序生产线任务上的大量实验表明，MAGPIE 实现了与奖励工程基线相当的性能，展示了其在精确奖励工程不可行的情况下促进策略学习的潜力。

## Abstract
Multi-agent reinforcement learning (MARL) is a powerful framework for solving complex collaborative tasks, but it relies heavily on well-defined global reward functions. Designing such rewards is challenging, especially in systems with heterogeneous agents, where a single scalar objective may fail to capture diverse behaviors. In this paper, we introduce Multi-AGent Preference-Integrated lEarning (MAGPIE), which addresses these challenges through agent-specific preference modeling. Each agent is evaluated by a dedicated expert through preference signals, eliminating the need for global evaluation. We theoretically prove that optimizing these decentralized preferences converges to a Nash equilibrium policy. To integrate local preferences into a coherent global objective, we construct agent-specific reward models from preference data and combine them via a monotonic aggregation mechanism. We further prove that optimizing this aggregate reward model is equivalent to training the Nash equilibrium policy. Extensive experiments on benchmark multi-agent tasks and a sequential production line task show that MAGPIE achieves performance comparable to reward-engineered baselines, demonstrating its potential to facilitate policy learning in scenarios where precise reward engineering is impractical.

### 1. 核心问题与研究动机

- **背景**：多智能体强化学习（MARL）在复杂协作任务中表现出色，但高度依赖精心设计的全局奖励函数。在真实系统中（如自动驾驶车队、工业生产线），智能体往往具有异构角色和目标任务，单一标量奖励难以兼顾所有智能体的行为与协作意图。
- **核心问题**：当系统规模增大、智能体角色分化时，奖励工程变得极其困难甚至不可行；而传统偏好强化学习（PbRL）直接扩展到多智能体场景面临三个主要障碍：
  - **全局偏好评估负担过重**：人类难以对整支团队的轨迹进行准确、一致的评价，规模越大、角色越多样，评估越容易出错。
  - **隐性同质性假设**：已有方法通过“跨智能体比较”来评估策略，隐含假定智能体之间具有可比性，不适用于异构系统。
  - **依赖真实奖励**：部分方法仍需真实奖励作为辅助监督，违背了摆脱奖励工程的初衷。
- **解决办法**：论文提出 **MAGPIE（Multi-AGent Preference-Integrated lEarning）**，用“每个智能体配备一个专属专家、提供智能体特定偏好”的方式取代全局奖励设计，理论上保证优化结果收敛至纳什均衡，并在实验中达到与奖励工程化基线相当的性能。

### 2. 方法论：MAGPIE 框架

#### 核心思想
- 将复杂的全局评估分解为多个局部、专一的智能体评估。
- 每个智能体 i 有一个专属“教师”（Teacher），该教师仅比较该智能体参与生成的两条轨迹段（segment）的优劣，提供二值偏好信号。
- 学习每个智能体的局部奖励模型，再通过单调聚合机制合成一个统一的全局奖励，供标准 MARL 算法（如 QMIX）使用。

#### 关键假设
- **Assumption 1**：每个智能体的偏好满足对称性、一致性和传递性。
- **Assumption 2**：存在可靠的教师提供偏好反馈。
- **Assumption 3**：真实全局奖励有界。
- **Assumption 4**：局部偏好与全局回报严格对齐——若教师偏好某个策略产生的轨迹，则该策略的真实全局收益严格更高。
- **Assumption 5**：每个智能体存在潜在局部奖励函数，教师的偏好与该局部回报的折扣累积一致。
- **Assumption 6**：全局奖励可表示为各局部奖励的连续可微函数 F。
- **Assumption 7**：智能体局部改进对团队总回报的负面影响有限，确保局部改进不降低全局聚合回报。

#### 理论结果
- **Theorem 1**：在有限状态/动作空间和 H→∞ 条件下，使用智能体特定偏好的迭代策略改进算法（Algorithm 1）最终返回的联合策略是纳什均衡。
- **Corollary 1**：如果轨迹段间回报差异有下界 δ，则有限段长 H 满足一定条件时即可保证纳什均衡。
- **Lemma 1**：F 对每个局部奖励严格递增是局部偏好与全局目标一致性的充分条件。
- **Theorem 2**：若局部奖励模型与教师偏好完全对齐，则最大化局部奖励之和的全局策略等价于真实奖励下的纳什均衡。
- **Theorem 3**：在充分偏好数据下，通过 Bradley-Terry 模型和交叉熵损失学习到的奖励模型可一致收敛到真实局部奖励（至多差一个仿射变换），并给出基于 Rademacher 复杂度的有限样本误差界。
- **Theorem 4**：有限样本导致的奖励误差会传播为策略上的 ϵ-纳什均衡误差，且当样本数 N→∞ 时 ϵ→0。
- **Theorem 5（附录）**：在线性分解 Q 结构下，使用随机逼近与 ODE 方法证明算法在随机采样条件下几乎必然收敛到最优 Q 函数。

#### 算法实现
- 偏好预测器使用 **Bradley-Terry 模型**建模：
  \[
  P_{\psi}[\sigma^{(1)} \succ_i \sigma^{(0)}] =
  \frac{\exp(\sum_t \gamma^t \hat{r}_i^\psi(s_t^{(1)}, A_t^{(1)}))}{
  \sum_{j\in\{0,1\}}\exp(\sum_t \gamma^t \hat{r}_i^\psi(s_t^{(j)}, A_t^{(j)}))}
  \]
- 奖励模型训练损失：
  \[
  \mathcal{L}_i = \mathcal{L}_i^{pref} + \lambda \mathcal{L}_i^{reg}
  \]
  - 交叉熵偏好损失 \(\mathcal{L}_i^{pref}\)
  - 正则损失 \(\mathcal{L}_i^{reg}\)：当局部偏好片段导致全局聚合回报下降时惩罚，保证 Assumption 7 的鲁棒性。
- **全局奖励聚合**：\(\hat{r}(s,A) = \sum_{i=1}^n \hat{r}_i^\psi(s,A)\)（加法单调聚合）。
- **训练技巧**：
  - 连续偏好采集（每 K 步采样新增轨迹段对）
  - 经验重标注（每次更新奖励模型后重算回放缓冲区中的所有奖励）

### 3. 实验设计

#### 基准与场景
- **MPE（Multi-Agent Particle Environment）三个基准任务**：
  - **Simple-Spread**：3 个同构智能体覆盖不同地标并避免碰撞，考验信用分配。
  - **Simple-Speaker-Listener**：一个静态说话者（广播地标 ID）和一个移动听者（导航到目标地标），两者观测和动作空间完全不同，高度异构。
  - **Simple-Reference**：两个智能体各自只知道部分目标地标，需互相协调，涉及不对称部分可观测性。
- **自定义实际场景：顺序手机生产线任务**
  - 三个环节：SMT（表面贴装）、Assembly（装配）、Test（测试）。
  - 每个环节由一个智能体管理，选择处理速度（低/中/高），平衡吞吐量与能耗，同时避免缓冲区溢出。
  - 新任务按泊松过程到达，各环节缓冲区容量有限，协作难度高。
  - 奖励函数由任务完成数、缓冲区溢出惩罚和能耗惩罚加权构成。

#### 对比方法
- **QMIX with task reward（oracle）**：使用环境真实奖励训练的标准 QMIX，作为奖励工程的上界基线。
- **MAPT**：基于全局偏好的多智能体对比方法。
- **Global-PbRL**：直接学习单一全局奖励模型的标准 PbRL 基线（冲突时随机赋偏好以模拟人类认知过载）。
- **MATD3**：使用真实奖励的另一个值函数方法。

#### 偏好生成
- 为每个智能体设计角色特定的启发式规则（如导航效率、通信一致性、局地目标接近度、能耗等），自动比较轨迹段得分生成偏好，无需人工标注。

#### 超参数与段长选择
- 偏好采集频率 K=500，每次每智能体采集 M=300 对轨迹段。
- 段长 H 在 MPE 任务中取 3、5、10；在生产任务中取 5、10、20。
- 训练总步数 1×10⁶ 或 3×10⁶，具体取决于任务。

### 6. 主要结论与发现

- MAGPIE 在多个基准任务和生产线任务中，仅凭智能体特定的分散偏好，即可达到与使用真实奖励的 QMIX（oracle）相当的性能。
- 理论证明局部偏好优化可收敛至纳什均衡，聚合奖励的最优策略与真实奖励的纳什均衡策略一致，且有限样本下为 ϵ-均衡。
- 启发式规则可以低成本替代人类标注，使得框架具备实际部署潜力。
- 相比全局偏好方法（Global-PbRL、MAPT），MAGPIE 能更好地处理异构智能体和团队评估冲突。
- 训练时间开销几乎可以忽略，适合大规模智能体系统。
- 消融表明：偏好学习模块、单调聚合、连续偏好采集和经验重标注均对最终性能至关重要；正则项能提高训练稳定性（尽管在完全合作场景下其缺失影响有限）。

### 7. 优点

- **创新性**：首次提出“n 对 n”的智能体-专家偏好机制，同时解决全局评估难、异构智能体不适配和奖励工程不可行三大问题。
- **理论完备性**：从偏好公理到纳什均衡再到有限样本误差，提供了层层递进的定理证明，并与实际算法形成闭环。
- **实用性强**：偏好来源可以是轻量级自动化规则或领域启发式脚本，不需要人类标注者；代码已开源。
- **通用性**：奖励模型训练模块与策略优化模块解耦，可直接替换现有 CTDE 类 MARL 算法（VDN、QMIX、MAPPO 等）。
- **实验覆盖多维度**：同构/异构、多智能体规模、不同段长、多种偏好生成规则、真实场景仿真，且使用多种基线。

### 8. 不足与局限

- **偏好生成规则的手工设计**：实验中的“教师”是作者自定义的启发式规则，未使用真实的人类偏好数据，尚不能完全证明在人机交互场景中的有效性。
- **理论假设较强**：如偏好与全局回报严格对齐（Assumption 4）、局部改进不损害全局（Assumption 7）在复杂现实环境中不一定成立，尽管正则项能部分缓解。
- **实验规模有限**：基准任务规模较小（智能体最多 6 个）；生产线任务也是简化模拟，未部署到实际物理环境。
- **未报告算力细节**：没有说明 GPU 型号、显存、卡数等，难以准确复现训练成本。
