## 摘要
在并发学习任务之间分配有限的计算资源是困难的，尤其当每个任务必须在截止日期前达到目标损失，而其所需的训练工作量未知时。现有方法将在线损失预测与自适应资源分配相结合，但通常将计算视为可连续划分的吞吐量。我们转而研究一种实际场景，其中任务随时间到达，计算由离散节点提供。该场景同时引入了不确定的需求和受限的序贯决策。我们提出了MARA，它利用条件流匹配预测未来损失轨迹，并通过协作式多智能体自回归策略协调计算节点。一种基于势能的进度奖励为中间训练提供反馈，同时保持无折扣的任务完成目标。在分布内、强化学习和视觉工作负载中，流匹配相比加权最小二乘法降低了剩余资源预测误差。在调度器的训练负载下，MARA平均完成63.46%的任务，比强基线“自适应资源分配学习”（LARA）高出8.54个百分点，并且在未见过的更重负载下仍保持领先。

## Abstract
Allocating limited computation among concurrent learning tasks is difficult when each task must reach a target loss before a deadline but its required training effort is unknown. Existing approaches combine online loss prediction with adaptive resource allocation, yet commonly treat computation as continuously divisible throughput. We instead study a practical setting in which tasks arrive over time and computation is provided by discrete nodes. This setting introduces both uncertain demand and constrained sequential decisions. We propose MARA, which predicts future loss trajectories with conditional flow matching and coordinates compute nodes through a cooperative multi-agent autoregressive policy. A potential-based progress reward supplies intermediate training feedback while preserving the undiscounted task-completion objective. Across in-distribution, reinforcement-learning, and vision workloads, flow matching reduces remaining-resource prediction error relative to weighted least squares. At the scheduler's training load, MARA completes 63.46% of tasks on average, 8.54 percentage points above strong baseline Learning with Adaptive Resource Allocation (LARA), and remains ahead under unseen heavier workloads.

- **核心问题**：在任务动态到达、计算资源由离散节点提供、需求未知的条件下，如何设计调度策略，使得尽可能多的任务在其截止日期前达到目标损失。

## 2. 论文提出的方法论

- **总体架构**：MARA 包含两个核心模块：
  - **条件流匹配预测器（FM Predictor）**：根据已观察到的损失历史，生成未来损失轨迹的分布，进而解码出每个任务完成所需剩余批次数（remaining batches）。
  - **多智能体自回归调度器（MAT）**：将每个计算节点视为一个智能体，按固定节点顺序以自回归方式构建任务–节点的有效匹配。
- **关键技术细节**：
  - **历史表示**：对任务损失历史使用 GRU 编码，同时拼接批大小、学习率、当前损失、预测视界等静态特征。为避免阈值依赖，不把目标损失 ε 输入预测器。
  - **目标构造**：将未来损失轨迹编码为 32 维向量，每个维度代表等宽采样区间内的平均损失，并采用累计损失和线性插值保证与已观测累计和一致。使用对数变换降低尺度差异。
  - **条件流匹配训练**：采用线性条件路径 z_u = (1−u)z₀ + u z₁，训练速度网络 v_θ 以拟合 z₁−z₀，损失为 L_FM = E[‖v_θ − (z₁−z₀)‖²]。推理时用少量 Euler 步积分，并用 Sobol 序列固定随机噪声以确保可重复性。
  - **需求估计**：对每个采样轨迹求损失首次越过 ε 的位置，得到剩余批次数估计，所有采样轨迹的中位数作为最终标量需求。若未越过，则使用生成上限。
  - **多智能体自回归分配**：使用 Multi-Agent Transformer（MAT），在节点顺序上自回归解码动作：p(a_t | o_t) = ∏ p(a_{i,t} | o_t, a_{1:t,<i})。通过掩码保证式 (2) 的约束（每个节点最多一个任务，每个任务最多被一个节点服务），无需事后修复。
  - **策略优化**：使用 PPO + GAE 训练，目标函数包含裁剪的代理目标、价值损失和熵正则。
  - **势能塑造奖励**：定义基于对数损失下降的进度 q_k(t)，状态势能为 Φ_t = Σ q_k(t)，训练奖励 r_t = r_success + β(Φ_{t+1} − Φ_t)。由于 γ=1 且端点势能为零，该稠密奖励不改变原始任务完成目标，从而缓解反馈稀疏问题。
  - **两阶段训练**：先固定任务曲线训练 FM 预测器（冻结），再在模拟器中训练 MAT 调度器，避免联合更新带来的非平稳性。
