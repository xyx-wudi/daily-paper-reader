## 摘要
离线多智能体强化学习（MARL）日益依赖生成式策略来建模多模态联合行为，通常是在集中训练分散执行（CTDE）框架下，将集中式教师蒸馏为分散式一步执行器。我们识别出教师训练阶段的一种失效模式：标准的基于流的教师模型将噪声与回放目标独立配对，因此相近的噪声样本可能被导向相互冲突的协同模式。随后教师会在有效模式之间产生样本，而由于蒸馏损失将每个局部执行器回归到给定局部输入下教师输出的条件均值，这种误差不会被吸收，而是传播给学生。为消除这种教师侧伪影，我们提出模式支撑半离散最优传输（MoSDOT），它将多模态回放数据概括为具有指定容量的有限模式支撑，并在教师训练前使用条件半离散最优传输将每个噪声样本分配到单一模式。我们还研究了一种共享随机性变体，其在执行时使用共享噪声分量，以揭示严格乘积执行所固有的残余差距。在受控诊断任务和离线 MARL 基准上，MoSDOT 提升了端点质量和路由一致性，尤其是在表现出多模态联合行为的数据集上。

## Abstract
Offline MARL increasingly relies on generative policies to model multimodal joint behavior, typically by distilling a centralized teacher into decentralized one-step actors under the CTDE. We identify a failure mode at the teacher training stage: standard flow-based teachers pair noise with replay targets independently, so nearby noise samples can be routed toward conflicting coordination modes. The teacher then produces samples between valid modes, and because the distillation loss regresses each local actor onto the conditional mean of the teacher's output given local input, this error is not absorbed but propagated to the student. To remove this teacher-side artifact, we propose Mode-Support Semi-Discrete Optimal Transport (MoSDOT), which summarizes multimodal replay into a finite mode support with prescribed capacities and uses conditional semi-discrete optimal transport to assign each noise sample to a single mode before teacher training. We additionally study a shared-randomness variant that uses a shared noise component at execution to expose the residual gap intrinsic to strict-product execution. On controlled diagnostics and offline MARL benchmarks, MoSDOT improves endpoint quality and routing consistency, particularly on datasets exhibiting multimodal joint behavior.

## 1. 核心问题与整体含义

- **研究背景**：离线 MARL 需要在 CTDE 框架下从固定数据集中学习协同策略。核心难点在于协同定义于所有智能体的联合动作分布上——每个智能体单独看似合理的动作可能组合成未见过的、不安全的联合动作。当数据包含多个有效协同模式时，单模态策略会把不同模式平均成无效的"中间动作"。
- **现有方案**：基于扩散和流匹配的生成式策略能建模多模态联合动作，但多步采样代价高、价值引导困难。近期工作采用"集中式生成教师 → 蒸馏为分散式一步学生"的范式。
- **核心失效模式（教师侧）**：标准流式教师将噪声与回放目标**独立配对**，导致邻近噪声样本被路由到相互冲突的协同模式，教师在有效模式之间生成无效样本。
- **误差传播**：由于 ℓ2 蒸馏损失将每个局部执行器回归到**给定局部输入下教师输出的条件均值**，教师侧的模式混合误差不会被吸收，而是传播给学生，导致学生坍缩到无效联合动作上。
- **整体含义**：论文将问题拆解为两个可分离的误差源——（i）教师侧源噪声路由伪影，（ii）严格乘积执行固有的"乘积投影差距"（product-projection gap），并针对前者提出解决方案。

## 2. 方法论

### 核心思想
用**条件半离散最优传输（SDOT）**在教师训练前将噪声空间划分为与模式容量匹配的 Laguerre 单元，使每个噪声样本被分配到单一协调模式，从而消除教师侧的模式纠缠。

### 关键技术细节

- **模式支撑（Mode Support）**：
  - 对每个条件上下文 $x$，收集 $M_x$ 个目标联合动作 $T_x$；
  - 通过聚合规则 $q_x$ 分组为 $K_x$ 个簇，每簇代表一个"模式" $y_k(x)$，构成离散支撑 $Y_x = \{y_1(x), \dots, y_{K_x}(x)\}$；
  - 离散动作基准用恒等支撑，连续动作基准用联合动作量化。

- **容量（Capacities）**：
  - 每个模式分配容量 $b_k(x) \ge 0$，$\sum_k b_k(x) = 1$；
  - 默认 $b_k(x) = |C_k(x)|/M_x$，即与回放经验频率匹配；
  - **关键**：源分配以完整联合模式 $y_k(x)$ 为单位，而非各智能体动作模式的乘积。

- **SDOT 源分配**：
  - 定义离散目标测度 $\nu_x = \sum_k b_k(x)\delta_{y_k(x)}$；
  - 求解 SDOT 对偶问题 $\Phi_x(g)$，得到最优对偶权重 $g_x^\star$；
  - 通过 Laguerre 单元定义源到模式的分配 $\Gamma_x(z) = \arg\min_k [c_x(z,k) - g_{x,k}^\star]$；
  - 成本 $c_x$ 取模式表示空间中的平方欧氏距离。

- **教师训练**：
  - 构造线性插值路径 $\bar{a}_t = (1-t)z + t\,y_{\Gamma(x,z)}$，位移 $v_\Gamma = y_\Gamma - z$；
  - 教师学习速度场 $u_\psi$，损失为 $\|u_\psi(\bar{a}_t, t, x) - v_\Gamma\|_2^2$。

- **联合策略蒸馏**：
  - 严格乘积学生：$\pi_w^{prod}(a|x) = \prod_i \pi_{w_i}(a_i|o_i)$；
  - 蒸馏损失：$\mathcal{L}_{distill} = \mathbb{E}\sum_i \|\mu_{w_i}(o_i, z_i) - [\mu_\psi(x,z)]_i\|_2^2$；
  - 价值引导版本加入 $-\alpha Q_{tot}(x, \hat{a})$ 项。

- **共享随机性变体（MoSDOT-SR）**：
  - 引入执行时共享信号 $h \sim \rho_h$，策略变为**乘积分布的混合**：$\pi_w^{sr}(a|x) = \int \prod_i \pi_{w_i}^{sr}(a_i|o_i,h)\rho_h(dh)$；
  - 智能体不交换观测/动作/消息，仅通过公共信号对齐模式选择；
  - 理论上可精确表示 XOR 型反相关支撑。

### 算法流程
1. 对每个缓存上下文构建路由模式支撑（聚合 + 容量）；
2. 求解 SDOT 得到 Laguerre 分配；
3. 训练 SDOT 对齐的教师；
4. 训练集中式 Critic（教师引导的自举）；
5. 蒸馏严格乘积学生（或共享随机性学生）。

## 6. 主要结论与发现

- **端点覆盖不等于可蒸馏**：教师即使能到达正确模式，若模式选择依赖局部不可观测的信息（如其他智能体的噪声），蒸馏仍会因条件均值回归而坍缩。Drifting 端点成功率高但路由一致性最低、Jacobian 非对角比最大。
- **MoSDOT 同时改善两个维度**：在端点轴上与最佳基线竞争（fan-free、success），并取得最佳 balance；在路由轴上取得最高 route consistency，Jacobian 非对角比与流匹配相当。
- **教师侧改进可传递给学生**：MoSDOT 学生保留教师 95.0% → 91.7% 的有效性，而 IMLE 损失一半（97.3% → 47.1%），Drift 完全坍缩（86.3% → 1.0%）。
- **严格乘积差距是残余约束**：即使教师完美，严格乘积学生也无法表示反相关支撑；共享随机性变体可闭合该差距（XOR 实验中从 (c) 到 (d) 的转变隔离了该误差）。
- **基准表现**：MoSDOT 在 SMAC 平均奖励 16.7（离散最优），MPE 平均 82.6（连续最优），尤其在 Medium/Random 等含多样化联合行为的数据集上优势明显；在单模式集中的 Expert 数据上提升有限。

## 7. 优点

- **问题识别精准**：明确区分教师侧路由伪影与乘积投影差距两个独立误差源，为 CTDE 生成式蒸馏提供了可测量的分析接口。
- **方法有理论支撑**：附录给出 ℓ2 蒸馏投影定理、块局部性分析、支撑误差与奖励上界、XOR 最小反例、共享随机性闭包证明，理论完整。
- **SDOT 应用得当**：将图像生成中的半离散最优传输迁移到 MARL 的联合动作模式路由，容量匹配机制自然对应回放频率。
- **诊断设计细致**：端点轴与路由轴分离评估，引入 Jacobian 非对角比、反事实翻转率等因果级指标，指标敏感性分析验证结论稳健。
- **共享随机性变体**：不交换观测/动作/消息，仅用公共信号即闭合 XOR 差距，为分散执行提供低通信成本的协调机制。
- **实验公平性**：统一架构、种子、数据划分，与 MAC-Flow 协议对齐，可比性强。

## 8. 不足与局限

- **严格乘积执行的根本限制**：独立局部采样无法表示任意相关联合支撑；共享随机性虽闭合可表示为乘积混合的支撑，但需要公共协调信道，实际部署中不一定可行。
- **共享维度需求未量化**：需要多少共享比特、信道何时可用，论文承认仍是开放问题。
- **实验规模有限**：最多 10 个智能体，动作空间为小离散或低维连续；未扩展到更大规模、更丰富动作空间或在线微调。
- **聚合规则简单**：离散用恒等规则、连续用固定 bin 量化；当联合动作空间增长快于每上下文回放覆盖时（如 terran_10_vs_10），恒等规则退化为样本级耦合，效果受限。
- **未与通信增强基线直接对比**：共享随机性变体未与使用更丰富跨智能体信道的通信类方法比较。
- **理论假设较强**：块局部性分析假设条件因子化训练律，实际中可能不完全成立。
- **应用限制**：仅针对离线场景，未涉及在线微调或动态环境适应；价值引导依赖 IGM 兼容 Critic。
