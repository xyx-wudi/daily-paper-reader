## 摘要
零和马尔可夫博弈出现在各种序贯决策问题中，例如对抗学习和针对建模不确定性的规划。然而，关于零和马尔可夫博弈所学状态-动作价值函数（$Q$函数）的有限样本保证的先前工作，大多局限于有限动作设置，或局限于智能体具有线性动力学和二次奖励的连续动作博弈（即线性二次（LQ）博弈）。将此类保证推广到更一般的连续动作零和马尔可夫博弈的一个核心挑战是，相关的贝尔曼算子涉及一个极小极大问题，而该问题未必具有可处理的鞍点解。为此，我们首先引入一类针对$Q$函数的神经网络函数逼近器，其在玩家动作上具有凸-凹性，从而保证该极小极大问题存在纯策略鞍点。然后，我们研究采用该函数类的在线拟合$Q$迭代变体，并据我们所知，首次为具有连续状态和动作的非LQ零和马尔可夫博弈建立了有限样本保证。我们的代码见 https://github.com/CLeARoboticsLab/QCanPlayThatGame。

## Abstract
Zero-sum Markov games arise in a wide variety of sequential decision-making problems such as adversarial learning and planning against modeled uncertainties. However, prior work on finite-sample guarantees on the learned state-action value function ($Q$-function) for zero-sum Markov games is largely restricted to finite-action settings, or to continuous-action games in which agents have linear dynamics and quadratic rewards (i.e. linear-quadratic, or LQ, games). A central challenge in extending such guarantees to more general continuous-action zero-sum Markov games is that the associated Bellman operator involves a minimax problem that need not admit a tractable saddle-point solution. To this end, we first introduce a class of neural network function approximators for the $Q$-function that is convex-concave in the players' actions, which guarantees that this minimax problem admits a pure-strategy saddle point. We then study an online variant of fitted $Q$-iteration employing this function class and establish, to the best of our knowledge, the first finite-sample guarantees for non-LQ zero-sum Markov games with continuous states and actions. Our code can be found at https://github.com/CLeARoboticsLab/QCanPlayThatGame.

## 2. 方法论

### 2.1 核心思想

- 设计一类**凸-凹神经网络 \(Q\) 函数逼近器**：
  \[
  Q_\theta(s,u,v)=N^1_{\theta_1}(s,u)-N^2_{\theta_2}(s,v)+u^\top M_{\theta_3}(s)v
  \]
  - \(N^1_{\theta_1}(s,u)\) 对 \(u\) 凸；
  - \(N^2_{\theta_2}(s,v)\) 对 \(v\) 凸，因此 \(-N^2\) 对 \(v\) 凹；
  - 双线性项 \(u^\top M_{\theta_3}(s)v\) 对 \(u\) 凸、对 \(v\) 凹，同时刻画玩家动作间交互。
- 该结构保证对每个状态 \(s\)，\(Q_\theta(s,\cdot,\cdot)\) 是凸-凹函数，因此内部 minimax 问题存在纯策略鞍点。

### 2.2 关键技术细节

- 基于 **PICNN（部分输入凸神经网络）** 构造 \(N^1,N^2\)：对指定输入方向保持凸性，同时不限制其他输入的表达能力。
- 通过 softplus 激活、非负权重重参数化等方式保证凸性；对状态路径可使用 ReLU 等普通激活。
- 双线性项中的 \(M_{\theta_3}(s)\) 用标准前馈网络输出矩阵，用于增强玩家动作耦合表达能力。
- 理论分析需要函数类的：
  - 有界性；
  - 联合动作 Lipschitz 连续性；
  - 覆盖数。论文在附录中给出了 PICNN 的 Lipschitz 界和 \(Q_\theta\) 的覆盖数上界。

### 2.3 算法流程：在线 Minimax Fitted Q-Iteration

- 输入：零和马尔可夫博弈、初始 \(Q_0\in\mathcal F\)、采样分布 \(\sigma\)、minimax oracle \(\mathcal O_\epsilon\)。
- 第 \(k\) 轮：
  1. 从 \(\sigma\) 采样 \(n\) 个状态-动作元组 \((s_i,u_i,v_i)\)；
  2. 对每个样本采样下一状态 \(s_i'\sim P(\cdot\mid s_i,u_i,v_i)\)；
  3. 调用 oracle 求近似鞍点：
     \[
     (\tilde u_i,\tilde v_i)=\mathcal O_\epsilon(Q_k(s_i',\cdot,\cdot))
     \]
  4. 构造回归目标：
     \[
     y_i=r(s_i,u_i,v_i)+\gamma Q_k(s_i',\tilde u_i,\tilde v_i)
     \]
  5. 在函数类 \(\mathcal F\) 上做最小二乘回归：
     \[
     Q_{k+1}=\arg\min_{f\in\mathcal F}\frac1n\sum_{i=1}^n(f(s_i,u_i,v_i)-y_i)^2
     \]
- 迭代 \(K\) 次后输出 \(Q_K\)。
