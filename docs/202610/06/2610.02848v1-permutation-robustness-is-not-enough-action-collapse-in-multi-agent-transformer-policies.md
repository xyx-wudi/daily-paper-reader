## 摘要
Transformer 策略对多智能体机器人学习具有吸引力，因为自注意力可以建模智能体之间的交互。然而，多智能体团队是无序的，而 Transformer 通常将智能体作为有序的 token 序列处理。我们研究这种不匹配如何在智能体顺序置换下影响合作导航策略。我们的结果表明，仅凭低置换误差可能具有误导性：策略可能看似鲁棒，仅仅因为所有智能体选择了相同动作。因此，我们同时使用置换一致性指标和动作坍缩诊断（包括动作多样性、相同动作比例和最大动作频率）来评估策略。PPO-ID 基线产生非坍缩行为，但仍对顺序敏感，而强等变性正则化仍可能诱导同质行为。对于 N=3 个智能体的团队，弱等变性惩罚在提高鲁棒性的同时保留了更多样的动作，而对于 N=4 个智能体的团队，则需要显著更小的正则化权重。这些发现表明，多智能体 Transformer 策略不仅应通过回报和置换鲁棒性来评估，还应通过其是否保持非坍缩、差异化的多智能体行为来评估。

## Abstract
Transformer policies are attractive for multi-agent robot learning because self-attention can model interactions among agents. However, multi-agent teams are unordered, while transformers typically process agents as ordered token sequences. We study how this mismatch affects cooperative navigation policies under agent-order permutations. Our results show that low permutation error alone can be misleading: policies may appear robust simply because all agents choose the same action. We therefore evaluate policies using both permutation-consistency metrics and action-collapse diagnostics, including action diversity, same-action fraction, and maximum action frequency. A PPO-ID baseline yields non-collapsed behavior but remains order-sensitive, while strong equivariance regularization can still induce homogeneous behavior. A weak equivariance penalty improves the robustness while preserving more diverse actions for teams with \(N=3\) agents, whereas teams with \(N=4\) agents require substantially smaller regularization weights. These findings suggest that multi-agent transformer policies should be evaluated not only by return and permutation robustness, but also by whether they maintain non-collapsed, differentiated multi-agent behavior.

## 1. 核心问题与整体含义

- **研究动机**：多机器人团队在物理上通常是“可交换实体”，例如无人机、地面机器人或操作臂，改变智能体在列表中的顺序不应改变各自应执行的动作。但 Transformer 策略通常把智能体当作有序 token 序列处理，并常加入可学习的智能体 ID 嵌入或位置嵌入。
- **核心问题**：Transformer 多智能体策略学到的是真正的协调行为，还是依赖智能体排列顺序的“槽位捷径”？论文进一步指出，仅用置换误差衡量鲁棒性可能被误导：策略可能因为所有智能体输出相同动作而获得很低的置换误差，看似鲁棒，实则发生“动作坍缩”。
- **整体含义**：评估多智能体 Transformer 策略时，不能只看任务回报和置换鲁棒性，还必须同时检查策略是否保持非坍缩、差异化的多智能体行为。论文将“顺序敏感性”“有用专业化”“同质动作坍缩”三种现象区分开，并强调对称性不是一个标量属性。

## 2. 方法论

- **核心思想**：将多智能体策略的置换等变性形式化为  
  \(f(PX)=Pf(X)\)，即输入智能体顺序被置换后，输出 logits 或动作应按同样方式置换。若策略依赖智能体 ID/位置嵌入，则物理智能体换到新 token 槽位后行为可能改变。
- **策略架构**：每个智能体观测映射为 128 维 token；加入学习到的智能体身份嵌入和序列位置嵌入；经过 2 个自注意力块、4 个注意力头；动作头为线性分类器，输出离散动作 logits。策略按智能体因子化，但每个因子通过 Transformer 注意力依赖全体观测；评论家为集中式评论家。
- **训练目标**：采用 PPO/MAPPO 风格训练，包含 PPO 裁剪损失、价值损失、熵奖励，并加入等变性正则项  
  \(L_{eq}=\|P^{-1}f_\theta(PX)-f_\theta(X)\|_2^2\)。还可选加入成对策略多样性正则  
  \(L_{pair}=-\frac{1}{N(N-1)}\sum_{i\neq j}\|\pi_i-\pi_j\|_2^2\)。总损失为  
  \(L=L_{clip}+c_vL_V-c_HH(\pi_\theta)+\lambda_{eq}L_{eq}+\lambda_{pair}L_{pair}\)。
- **算法流程**：初始化 Transformer actor-critic；每个 PPO 更新中收集 rollout 并计算 GAE；对每个 minibatch 计算 PPO 损失和价值损失；采样一个置换并计算等变性损失；可选计算成对多样性损失和熵损失；更新参数；最后在 normal、random、reversed 三种排序下评估性能、鲁棒性和坍缩指标。
- **置换一致性指标**：包括 logit 等变误差 \(E_{eq}\)、策略 KL 散度、贪心动作不一致率 \(D_{act}\)。
- **动作坍缩诊断**：包括归一化动作多样性 \(D_{div}\)、相同动作比例 \(F_{same}\)、最大动作频率 \(F_{max}\)。若所有智能体始终选择相同动作，则 \(D_{div}=1/N\)，这是坍缩下限。
- **理论解释**：无槽位特定嵌入时，自注意力本身是置换等变的；但学习到的 ID/位置嵌入通常破坏该性质。若策略对所有智能体输出相同 logits，则任意置换下等变误差为零，但并未学到差异化协调。

## 3. 实验设计

- **场景与 benchmark**：使用 PettingZoo/MPE 的 cooperative navigation 合作导航任务。主实验为 \(N=3\) 个智能体与 3 个地标；压力测试为 \(N=4\) 个智能体与 4 个地标。任务要求智能体覆盖地标并避免低效配置，适合诊断顺序敏感性和动作坍缩。
- **排序干预**：评估时使用三种模式：normal 规范顺序、random 随机置换、reverse 反转顺序。置换后前向传播得到的 logits 和动作会被反置换回原物理智能体顺序，再计算指标或执行动作，以隔离顺序影响与物理状态变化。
- **对比方法**：
  - PPO-ID：带智能体 ID/位置嵌入的 PPO Transformer 基线。
  - PPO-ID+Eq，\(\lambda_{eq}=0.01\)：弱等变性正则。
  - Eq，\(\lambda_{eq}=0.05\)：强等变性正则。
  - Eq+Pair，\(\lambda_{eq}=0.05,\lambda_{pair}=0.007\)：等变性加成对策略多样性正则。
  - \(N=4\) 压力测试中扫描更小系数，如 \(2.5\times10^{-4}\)、\(5\times10^{-4}\)、\(10^{-3}\)、\(10^{-2}\)、\(5\times10^{-2}\)。
- **评估指标**：任务回报 Return；随机置换下的 \(E_{eq}\)、KL、\(D_{act}\)；正常排序下的 \(D_{div}\)、\(F_{same}\)、\(F_{max}\)。评估使用每个排序模式 200 个 episode。
- **Benchmark 性质**：该 benchmark 不是大规模标准排行榜，而是受控诊断环境，重点在于揭示回报、置换鲁棒性和动作多样性之间的混淆关系。
