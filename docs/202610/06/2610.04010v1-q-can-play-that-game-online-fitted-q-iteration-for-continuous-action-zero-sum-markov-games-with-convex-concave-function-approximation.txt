## ABSTRACT 

Zero-sum Markov games arise in a wide variety of sequential decision-making problems such as adversarial learning and planning against modeled uncertain-ties. However, prior work on finite-sample guarantees on the learned state-action value function ( Q-function) for zero-sum Markov games is largely restricted to finite-action settings, or to continuous-action games in which agents have linear dynamics and quadratic rewards (i.e. linear-quadratic, or LQ, games). A central challenge in extending such guarantees to more general continuous-action zero-sum Markov games is that the associated Bellman operator involves a minimax problem that need not admit a tractable saddle-point solution. To this end, we first introduce a class of neural network function approximators for the 

Q-function that is convex-concave in the players’ actions, which guarantees that this minimax problem admits a pure-strategy saddle point. We then study an online variant of fitted Q-iteration employing this function class and establish, to the best of our knowledge, the first finite-sample guarantees for non-LQ zero-sum Markov games with continuous states and actions. Our code can be found at 

https://github.com/CLeARoboticsLab/QCanPlayThatGame .

## 1 INTRODUCTION 

We consider the problem of learning state-action value functions ( Q-functions) in discounted, infinite-horizon, two-player zero-sum Markov games with continuous state-action spaces. Such games naturally arise in competitive scenarios and robust decision-making, where environmental uncertainties and disturbances are adversarially modeled (Zhou et al., 1996; Morimoto & Doya, 2000; Pinto et al., 2017). Prior work has established finite-sample guarantees for zero-sum Markov games in the finite-action setting (Lagoudakis & Parr, 2002; Perolat et al., 2015; Zhao et al., 2022; Fan et al., 2020; Zhang et al., 2021a; Jia et al., 2019; Sidford et al., 2020; Xie et al., 2020; Alacaoglu et al., 2022; Chen et al., 2024; Feng et al., 2024). However, extending these results to the continuous state-action setting remains challenging. The difficulty stems from the minimax problem on Q inside the Bellman operator. At every state, each player wishes to play a security strategy, meaning that one player’s policy solves a min max problem and the other’s solves a max min . The solutions to these two distinct problems are mutually consistent at saddle points , where both players have non-exploitable security strategies. Saddle points are guaranteed to exist when policies map from state to mixed strategies over the action space. In finite-action spaces, the resulting saddle-point problem can be solved via a linear program; in continuous action spaces however, it is generally intractable to compute mixed-strategy saddle points as mixed-strategy spaces are infinite-dimensional. Moreover, when policies are restricted to output pure strategies at each state, i.e. raw actions, saddle-point solutions generally do not exist for arbitrary Q.1arXiv:2610.04010v1 [cs.GT] 2 Oct 2026 Preprint In this work, we propose a new class of neural network function approximators of the Q-function which is convex in the minimizing player’s action and concave in the maximizing player’s action. This convex-concave structure addresses the challenge above, as the minimax theorem guarantees that a pure-strategy saddle point exists for the minimax problem inside the Bellman operator. Fur-ther, this pure-strategy saddle point can also be reliably computed up to any desired accuracy using existing minimax optimization methods (Nemirovski, 2004; Lin et al., 2020). We analyze an on-line variant of minimax fitted Q-iteration which employs this convex-concave function class and establish finite-sample bounds between the learned Q-function and the fixed point of the Bellman operator, assuming that the fixed point admits pure-strategy saddle points. The prior work closest to ours establishes finite-sample bounds for online minimax fitted Q-iteration with neural network function approximation, but is restricted to finite-action spaces (Fan et al., 2020). In the continuous-action setting, single-player reinforcement learning literature has devel-oped finite-sample analysis for fitted Q-iteration with function approximation (Antos et al., 2007). However, extending these results to the zero-sum Markov game setting remains underexplored. Within the game setting we consider, theoretical finite-sample results for continuous state-action domains remain largely confined to the linear-quadratic (LQ) setting, where agents have linear tran-sition dynamics and quadratic objectives (Bas ¸ar & Olsder, 1998; Al-Tamimi et al., 2007a;b; Zhang et al., 2019; Bu et al., 2019; Zhang et al., 2021b). These results exploit the fact that in the LQ setting, the optimal Q-function and the resulting policies admit a closed-form solution via the algebraic Ric-cati equations (Bas ¸ar & Olsder, 1998). Unfortunately, this Riccati structure does not extend beyond the LQ setting. In this work we move beyond the LQ setting, and make the following contributions: • Contribution 1. We propose a new class of neural network function approximators for the Q-function of zero-sum Markov games. Building on the partially input convex neural network architecture (Amos et al., 2017), this class is convex in the minimizing player’s ac-tions and concave in the maximizing player’s actions by construction. The convex-concave structure ensures the existence of a saddle-point solution to the minimax problem in the Bellman operator. • Contribution 2. We analyze batched minimax Q-learning employing the above function approximation class, and establish finite-sample bounds comparing the learned Q-function to the fixed point of the Bellman operator, assuming the fixed point admits pure-strategy saddle points. To the best of our knowledge, this is the first such bound for neural network function approximation in zero-sum Markov games with continuous state-action spaces beyond the LQ setting. Additionally, we empirically investigate whether these convex-concave neural networks lead to sta-ble training when used on a practical version of modified fitted Q-iteration.

Remark 1 (Mixed Strategies) . An alternative route to ensure existence of a saddle-point solution is to let players employ mixed strategies, where they randomize over pure strategies. In the finite-action setting, mixing ensures that a saddle point of the minimax problem always exists, and it can be computed by solving a linear program at every state s. In the continuous-action setting, a saddle point over mixed strategies still exists under mild continuity assumptions (Glicksberg, 1952), but computing it is far less straightforward than in the finite-action setting. The iterative double oracle algorithm (Adam et al., 2021) is guaranteed to return a saddle point up to any desired accuracy; however, each iteration requires computing a global best response for each player, which can be intractable under function approximation. Moreover, an explicit bound on the required number of iterations as a function of the saddle-point accuracy remains unknown. These difficulties motivate our focus on pure strategies with convex-concave function approximation instead.

## 3 CONVEX -C ONCAVE FUNCTION APPROXIMATION 

We now describe the convex-concave neural network architecture used to approximate the Q-function: for every network parameter vector θ ∈ Θ, and every state s ∈ S , the Q-function network 

Qθ : ( S ×U ×V ) → R should be convex-concave, i.e., Qθ (s, u, v) must be convex in u ∈ U for ev-ery fixed (s, v) and concave in v ∈ V for every fixed (s, u). To construct such a network, we build 3Preprint on partially input convex neural networks (PICNNs) (Amos et al., 2017), a network architecture that guarantees convexity in a designated subset of the network’s inputs, while simultaneously leaving the dependence on the other inputs unconstrained. Formally, given two inputs x and y where con-vexity in y is desired, the PICNN architecture constructs a neural network Nθ (x, y), such that for every choice of parameters θ, Nθ (x, y) is convex in y for fixed x, while retaining full expressivity in x. PICNNs achieve this by constraining a subset of weights along the computation graph edges traceable back to y to be non-negative and pairing them with convex, non-decreasing activations, while leaving weights traceable to x unconstrained. We review the PICNN architecture in more detail in Section C. The presence of δ2approx in the bound represents the cost of working with a restricted, tractable convex-concave function class F. δapprox will be 0 when the underlying game satisfies Bellman completeness. F. Unlike the finite-action setting, continuous action spaces cannot be covered exactly with finitely many samples. The parameters η1, η 2 > 0 correspond to this covering tradeoff. ## 6 CONCLUSION 

We study the learning of Q-functions in infinite-horizon zero-sum Markov games in continuous state and action spaces. Prior finite-sample guarantees of Q-function learning have largely been confined to either games with finite-actions or to continuous linear-quadratic games, where the agents have linear dynamics and quadratic rewards. A key challenge in extending the guarantees of these prior works to more general continuous-action zero-sum Markov games is that the associated Bellman equation involves a minimax problem that is not guaranteed to admit a tractable saddle-point solu-tion in pure strategies. To address this issue, we introduce a class of neural network function ap-proximation for Q which is convex-concave in the players’ actions, guaranteeing that the minimax problem admits a pure-strategy saddle point that can be computed efficiently by existing solvers. We study an online variant of the fitted Q-iteration algorithm employing this function class and es-tablish, to the best of our knowledge, the first finite-sample guarantees for continuous state-action zero-sum Markov games beyond the linear-quadratic setting. Finally, we empirically validate that these convex-concave neural networks lead to stable training when used on a practical version of modified fitted Q-iteration. The empirical results naturally point to a future work direction of ex-tending the finite-sample analysis for the practical temporal difference-style variant of Theorem 1 studied in Section 5, in which the exact regression step of Algorithm 1 is replaced by a single gradi-ent step, as in Section 5.
