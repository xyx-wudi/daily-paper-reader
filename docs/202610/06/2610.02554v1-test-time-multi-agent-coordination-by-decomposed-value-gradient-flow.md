## 摘要
离线多智能体强化学习（MARL）面临一个长期存在的权衡。具有表达力的生成式策略能够表示数据中的多模态协调，但无法区分高价值区域；而价值优化策略利用学到的 Q 函数，却将多模态坍缩为单一主导模式。单个智能体的模式坍缩可能破坏联合协调，而多个智能体同时漂移可能将联合策略推向动作空间中的未见区域。我们提出通过最优统一传输的可扩展协调（SCOUT），这是首个通过测试时动作细化将生成式基础模型与学习到的价值函数相结合的离线 MARL 框架。SCOUT 训练两个解耦组件：一个流匹配行为先验和一个分解价值函数。在测试时，它通过 Stein 变分梯度下降将行为样本传输至高价值区域。传输步数控制自适应测试时缩放，取代固定的正则化系数。在个体-全局-最大（IGM）原则下，我们证明了联合软价值差距上的单项 KL 界，该界随传输收敛而消失，并具有一个与 IGM 违反程度成正比的不可约加性残差。经验上，SCOUT 在离散和连续离线 MARL 基准上取得了最佳平均性能，并在所有离线到在线配置中带来性能提升。

## Abstract
Offline multi-agent reinforcement learning (MARL) faces a persistent trade-off. Expressive generative policies can represent multi-modal coordination in the data, but cannot distinguish high-value regions, while value-optimized policies exploit the learned Q-function but collapse the multi-modal into a single dominant mode. A single agent's mode collapse can break joint coordination, and simultaneous drift across agents can push the joint policy into unseen regions of the action space. We propose scalable coordination via optimal unified transport (SCOUT), the first offline MARL framework to combine a generative foundation model with a learned value function through test-time action refinement. SCOUT trains two decoupled components: a flow-matching behavioral prior and a decomposed value function. At test-time, it transports behavioral samples toward high-value regions via Stein variational gradient descent. The number of transport steps controls adaptive test-time scaling, replacing a fixed regularization coefficient. Under the individual-global-max (IGM) principle, we prove a single-term KL bound on the joint soft-value gap that vanishes as transport converges, with an irreducible additive residual proportional to the IGM violation. Empirically, SCOUT achieves the best average performance across discrete and continuous offline MARL benchmarks and yields performance improvements in all offline-to-online configurations.

- **离线 MARL 的根本两难**：离线多智能体强化学习需要在无法主动采集数据的安全攸关场景（自动驾驶、物流、机器人）中，从异构、次优的演示数据里学到协调行为，同时避免分布外（OOD）漂移。
- **表达力与价值优化的冲突**：
  - 生成式策略（扩散、流匹配）能表示数据中的多模态协调结构，但**无法区分高价值区域**。
  - 价值优化策略能利用学到的 Q 函数，却会**将多模态坍缩为单一主导模式**。
- **多智能体下的复合困难**：
  - 单个智能体的模式坍缩会破坏联合协调；多个智能体同时漂移会把联合策略推入动作空间中**数据从未访问过的区域**（Q 函数最不可靠处）。
  - 训练时的固定正则化系数只能约束各边缘分布，**无法约束联合分布的复合漂移**；且一旦在训练时把各边缘锁定到某个贪心模式，后续新交互数据也无法再用来区分哪个模式真正更高价值。
- **核心追问**：如何**避免为价值最大化显式参数化策略**，改为在测试时通过把行为样本直接输运至高价值区域来恢复协调？
- **整体含义**：论文提出 SCOUT，首次将**生成式基础模型（流匹配行为先验）**与**学习到的分解价值函数**通过**测试时动作精修**结合，用传输步数替代固定正则化系数，实现自适应测试时缩放。

## 2. 方法论

### 核心思想
- **解耦训练、测试时精修**：行为建模与价值提升彻底分离。行为先验不被训练期价值损失形变，价值引导只在推理时施加。
- 类比 MaxEnt 代理目标的最优 Boltzmann 策略 π*(a|s) ∝ exp(Q/α)，但**不拟合显式 actor**，而是构造一个输运映射把行为样本推向该目标。

### 关键技术细节
- **组件一：流匹配行为先验（每智能体）**
  - 学习每个智能体的速度场 v_w(t, o_i, x_t)，用条件线性路径 x_t=(1−t)x_0+tx_1 的流匹配损失训练（式 7）。
  - 推理时用固定步长 Euler 积分（10 步）生成动作候选，保持多模态、保持在行为支持附近。
- **组件二：分解价值函数**
  - 采用最简单的加性分解 Q_tot(o,a) = Σ_i Q_θi(o_i,a_i)（VDN 式），满足 IGM。
  - TD 目标 y = r + γ Q_tot(o′, a′)，其下一步动作 a′ 由**精修后的粒子**给出（训练期也用 L_train 步精修）。
- **组件三：测试时分解梯度输运（核心）**
  - 每个智能体从行为流策略采样 P 个动作粒子 a^(0)_{i,j}，然后按 SVGD 迭代 L 步精修（式 8）：
    - 第一项：**核平滑的价值梯度**（驱动粒子移向高 Q_i 区域）；
    - 第二项：**排斥力**（RBF 核，自适应中值带宽，防止粒子坍缩、保留多模态）。
  - 更新式：a^(ℓ+1) = a^(ℓ) + ε · clip(φ̂_i)，每步对梯度做裁剪。
  - **离散动作空间**：在 logit 空间精修，价值梯度为 ∇_ℓ Σ_a softmax(ℓ)_a · Q_i(o_i,a)，通过 softmax 自动微分得到。
  - 最终每智能体独立选 Q_i 最高的粒子作为执行动作。
- **自适应测试时缩放**：L_test = 0 退化为 best-of-P 采样；L_test = L_train 匹配训练条件；L_test > L_train 在 Q 泛化良好时进一步放大精修。传输预算 (L_test, ε) 无需与训练一致。

### 理论分析
- **Assumption 4.1**：Q_tot = Σ_i Q_i + Δ，残差 ‖Δ‖_∞ ≤ δ。
- **Theorem 4.2（近似 IGM 下的软价值间隙）**：
  0 ≤ J_soft(π*_joint) − J_soft(π̃_L) ≤ **α·KL(π̃_L ‖ ∏π*_i) + 4δ**。
  其中 KL 项为输运误差，在理想化 SVGD 下随 L→∞ 消失；4δ 为不可约的 IGM 违反残差（2δ 来自每智能体输运目标，2δ 来自因子化与联合 Boltzmann 最优解之差），对所有分解 Q 方法同样适用。SCOUT 的独特之处是**输运误差可在测试时增大 L 来降低，无需重训**。
- **Proposition 4.3（分解输运近似联合 best-of-P）**：
  (i) Δ=0 时，各智能体独立输运+独立选择产生 Cov(a*_i, a*_i′)=0 且联合最优；
  (ii) ‖Δ‖_∞≤δ 时，Q_tot(a*_1,…,a*_I) ≥ max_j Q_tot(a^(L)_{1,j},…,a^(L)_{I,j}) − 2δ。
- **隐式协调来自 TD 目标**：在 TD 不动点处，Q_i 的梯度可近似为 E_{a_−i∼ρ}[∇_{a_i}Q_tot]，加性分解下 ∇_{a_i}Q_i 保持联合梯度的符号，因此**协调是从训练分布继承的，而非测试时凭空合成**，输运只是通过核平滑重复更新将其放大。

## 6. 主要结论与发现

- **RQ1（离线性能）**：SCOUT 在 SMACv1 与 MA-MuJoCo 上均取得最高平均分——SMACv1 平均奖励 16.1（MAC-Flow 14.9、MADiff-D 15.2、高斯族最高 14.4）；MA-MuJoCo 归一化平均 82.12（MAC-Flow 76.37、MADiff-D 68.52）。与同骨干的 MAC-Flow 对比凸显了测试时价值输运优于训练时蒸馏。
- **RQ2（离线到在线）**：SCOUT 在**所有**离线到在线配置中均带来提升，且在 Poor 数据上优势最明显。原因是行为先验从未被训练期价值损失形变，在线阶段只需调整传输预算即可利用新数据，而非去“纠正”一个被低质演示锚定的策略。
- **RQ3（超参敏感性）**：L_test = 0 到少量精修步即可带来明显提升，证明分解价值梯度输运在 best-of-P 之外确实增加了协调；但最优 L_test 因场景/数据质量而异，过度精修（如 L_test=10）在部分情况下反而退化，说明 Q 函数在动作被输运过远后精度下降。
- **玩具例子**：MAC-Flow 的训练时妥协使策略坍缩到原点附近；SCOUT 保留多模态先验，5 步精修即可把候选推向最优模式。
- **理论结论**：在近似 IGM 下，联合软价值间隙由单项 KL（可随 L 增大而降低）+ 不可约 4δ 界定；分解输运与集中式 best-of-P 的差距不超过 2δ。

## 7. 优点

- **范式创新**：首次在离线 MARL 中提出“策略无关（policy-free）的价值最大化”，把行为建模与价值提升彻底解耦，用测试时精修预算替代训练时正则化系数。
- **自适应测试时缩放**：L_test 是一个部署期可调、无需重训的旋钮，天然适配 Q 函数泛化能力与数据质量差异。
- **保留多模态**：SVGD 的排斥项避免粒子坍缩，直接针对“多智能体联合模式被贪心压掉”这一核心痛点。
- **理论与方法契合**：在 IGM 框架下给出**单项 KL + 4δ** 的清晰分解，并明确指出 4δ 是所有分解 Q 方法共有的不可约项，而输运误差是 SCOUT 独有的可压缩项；Proposition 4.3 证明分散式精修相对集中式精修仅损失 2δ。
- **协调来源可解释**：通过 TD 目标论证 ∇_{a_i}Q_i 继承联合梯度符号，说明协调是训练期习得、测试期放大，而非测试时凭空生成。
- **工程细节扎实**：离散动作在 logit 空间精修、正弦时间嵌入（K=8 Fourier 特征）、梯度裁剪、RBF 核自适应中值带宽等实现细节均有交代。
- **实验覆盖较全**：离散+连续、多数据质量、离线到在线、超参扫描，且 8 seeds 报两倍标准差。
