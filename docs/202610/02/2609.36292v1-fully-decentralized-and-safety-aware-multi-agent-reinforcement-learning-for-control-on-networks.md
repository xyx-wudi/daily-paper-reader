## 摘要
本文提出一种安全且完全去中心化的多智能体强化学习（MARL）算法，用于求解网络上一类离散时间控制问题，包括持续监测问题。智能体的完全去中心化控制虽然带来诸多好处，但也面临样本复杂度指数增长、缺乏系统全局信息以及智能体间协调困难等问题。为解决这些问题，本文提出一种完全去中心化的多智能体强化学习算法，将深度强化学习与安全考量相结合。该方法将网络状态的局部观测历史输入两个并行的神经网络分支：图编码器，用于加入结构信息以及节点间的相关性；状态估计器，用于预测图中每个节点的不确定性。此外，将该输入送入 Actor-Critic 网络所得结果会经过一个离散时间控制障碍启发式方法，以降低任何节点被忽略的可能性。该方法通过提高系统感知能力，并内置安全措施以防止采用可能有害的控制策略，使完全去中心化的智能体团队能够解决具有挑战性的问题。来自自定义仿真环境的数值结果表明，所提算法的平均不确定性比集中式控制策略低 26.3%，并且与一个计算更复杂、增加了注意力层的算法的不确定性性能相差在 1% 以内。

## Abstract
This paper develops a safe and fully decentralized multi-agent reinforcement learning (MARL) algorithm to solve a class of discrete-time control problems on networks, including the persistent monitoring problem. Fully decentralized control of agents, while offering numerous benefits, faces issues such as exponentially increasing sample complexity, lack of global information about the system, and challenges in coordinating between agents. To address these issues, this paper introduces a fully decentralized multi-agent reinforcement learning algorithm that integrates deep reinforcement learning with safety considerations. This method feeds a history of local observations of the network's state into two parallel neural-network branches: the graph encoder, which adds structural information and correlations among nodes, and a state estimator, which predicts the uncertainty at each node in the graph. Additionally, the result of feeding that input into an actor-critic network is passed through a discrete-time control barrier heuristic to reduce the likelihood that any node will be neglected. This approach enables teams of fully decentralized agents to solve challenging problems by increasing system awareness and incorporating built-in safety measures to prevent the adoption of potentially harmful control policies. Numerical results from a custom simulation environment demonstrate that the proposed algorithm achieves 26.3 percent lower average uncertainty than a centralized control policy and is within 1 percent of the uncertainty performance of a more computationally complex algorithm with added attention layers.

- **整体含义**：论文主张将 **深度强化学习（泛化能力）+ 安全方法（确定性行为与协调）** 结合，通过增强系统感知与内嵌安全约束，使完全不通信的智能体团队仍能有效完成网络控制任务。

## 2. 方法论

### 核心思想
每个智能体仅基于自身的局部观测历史构建"心理地图"，经图编码器与状态估计器两条并行分支处理后送入 Actor-Critic，输出再经离散时间控制屏障函数（DCBF）启发式过滤，剔除可能导致节点被忽视的动作。

### 关键技术细节与流程

- **心理地图（Mental Map）$M_{i,k}$**：
  - 用于在局部观测不完整（$\Omega_{i,k} \subset G$）时维持对网络的时序推理；
  - 新观测覆盖对应存储值，未观测节点保留旧值；初始化为空节点，使网络规模固定，节省计算。

- **图拉普拉斯增强**：将 $L_{i,k} = D_{i,k} - A_{i,k}$（度矩阵减邻接矩阵）与心理地图拼接，为智能体提供内建的结构信息，使其在信息不全时也能在节点间移动。

- **图注意力网络（GAT）**：对增强后的状态信号进行变换，学习相邻节点间的相关性，公式为多头注意力聚合 $\vec{f}'_m = \|_{h=1}^{H} \sigma\left(\sum_{j \in N_m} \alpha_{mj}^h W^h \vec{f}_j\right)$，其中 $\sigma$ 为 LeakyReLU。

- **状态估计器 $L_i$（MLP）**：
  - 预测不可见节点的特征（即各节点不确定性），损失为均方预测误差：
    $\text{loss}(L_i) = \frac{1}{|V|}(L_i(M_{i,k-1}) - M_{i,k})^2$；
  - 使智能体能学习状态动力学映射，并因深度网络的泛化性对相似状态产生相似输出。

- **Actor-Critic 结构**：将图编码器与状态估计器输出拼接后送入线性策略头（输入维度 5×节点数）与价值函数（3×节点数，1 输出层），线性层设计以降低计算成本。

- **离散时间控制屏障函数（DCBF）启发式**（核心安全机制）：
  1. **节点掩码**：动作限制在当前节点及一步邻域内，其余概率置零；
  2. **下界计算**：$h_t = \max(L(V_m)) \cdot (1-\eta)$，$\eta=0.1$，即只有不确定性不低于最大值 90% 的节点才会被考虑；
  3. **不安全节点判定**：低于阈值节点的选择概率乘 0，否则乘 1；若无可行动作，则选估计不确定性最高的可达节点（随机打破平局）；
  4. **停留冻结**：智能体在节点停留 10 步，确保该节点不确定性被充分降低。
  - 安全定义为：没有任何目标节点的不确定性超过阈值 $\gamma_k$（等于训练/测试的步数）。

- **奖励函数**：$r_{i,k} = W_{col}\,col_i + W_{change}\,change_i + W_{mom}\,mom_{i,t}$
  - $col_i$：碰撞惩罚（同节点重叠为 -3，否则 0）；
  - $change_i = \bar{U} - U_i$：与过去 $W=10$ 回合平均不确定性之差，反映进展；
  - $mom_{i,t}$：停留时不确定性未下降则递减的动量项；
  - 三项权重均取 0.05，以避免奖励信号过大导致训练不稳定。

- **空间到网络的建模（Algorithm 1）**：将任意 $n$ 维矩形空间按步长 $m_n$ 划分为离散块作为节点，块间相邻关系作为边，输出节点列表与边列表，使算法不局限于天然网络化场景。

## 3. 实验设计

### 场景与数据集
- **自建 Python 仿真环境**，依赖 NetworkX、PyTorch、PettingZoo。
- 网络按随机过程生成：任意两节点连边概率 20%，节点为目标概率约 16%。
- **三种代表性规模**（均使用 4 个智能体）：
  - 50 节点 / 8 目标节点；
  - 100 节点 / 17 目标节点；
  - 200 节点 / 32 目标节点。
- 节点不确定性上限设为 100；每个智能体训练 100 回合、每回合 500 步。

### Benchmark 与对比方法（实验一）
- **Grazing**：全知全能型集中式算法（拥有完整状态信息）；
- **Random policy**：随机动作选择；
- **Sit-on-nodes policy**：选定目标节点后一直停留；
- **Centralized Algorithm**：共享心理地图、状态估计器与观测处理网络的集中式版本（近似 [8]，但不含状态历史与时空注意力）。

### 消融与变体分析（实验二）
- **No DCBF**：移除控制屏障启发式；
- **No State Est.**：移除状态估计器；
- **No Collisions**：用防碰撞的 DCBF 变体替代原启发式；
- **Extra Attention**：额外添加多层单头注意力与图变换层。

### 评价指标
- **平均不确定性（Average uncertainty over time）**：各节点不确定性之和在时间上的算术平均；
- **最大目标访问间隔（Max. time between any target visit）**：反映策略是否倾向将智能体困于小范围而忽视节点。

## 6. 主要结论与发现

- **相对集中式算法的优势**：所提算法的平均不确定性为 **1736.3**，比集中式算法（2356.7）低 **26.3%**，验证了完全去中心化在特定任务上的可行性。
- **与全知基准的差距**：Grazing（1128.1）最优，所提算法比其高 53.9%，集中式算法比其高 108.9%；但 Grazing 假设完美状态信息，实际不可实现。
- **与复杂模型的对比**：带额外注意力层的变体平均不确定性 1734.6，仅比所提算法优 **不到 1%**，却需要额外 1 个单头注意力层与图变换层（5 层、5×5、各 1 头），说明轻量结构已接近性能上限。
- **安全机制的关键作用**：移除 DCBF 后平均不确定性退化到饱和值 3006.0，访问间隔达饱和，说明 DCBF 是防止节点被忽视的**必要组件**。
- **消融发现**：No Collisions 与 No State Est. 变体性能约差 1%，前者在两项指标上均略优且方差相近，提示防碰撞版本值得进一步探索，也表明在算力受限或不允许碰撞的场景下可作取舍。
- **访问间隔的短板**：所提算法的平均最大访问间隔为 1176.6，而集中式与 Grazing 分别降低 72.6% 和 76.5%，说明去中心化策略更倾向于优化局部小环境，全局探索能力有限。

## 7. 优点

- **问题选择精准**：将完全去中心化的"局部优化"特性与持续监测问题的结构匹配，论证了问题选择对算法成败的重要性。
- **方法论组合新颖**：将图注意力、状态估计器、Actor-Critic 与离散时间控制屏障函数有机整合，兼顾学习能力、结构感知与安全保障。
- **真正意义上的完全去中心化**：训练与评估阶段均无信息共享、无参数共享、无通信，规避了通信开销与实现复杂度。
- **工程可落地性强**：
  - 心理地图初始化为空节点以固定网络规模，降低计算开销；
  - 策略头与价值函数使用线性层，计算成本低；
  - 提供 Algorithm 1 将任意 $n$ 维矩形空间自动分解为图，扩展了适用场景。
- **实验分析较规范**：同时报告均值与标准差，进行消融与变体分析，并辅以 ANOVA 显著性检验。
- **坦诚的自我评估**：明确指出在最大访问间隔指标上落后于集中式方法，未回避去中心化策略的局部化倾向。

## 8. 不足与局限

- **实验覆盖有限**：
  - 仅一个自建仿真环境，无公开基准或真实机器人/无人机平台验证；
  - 智能体数量恒为 4，未验证方法在更大团队下的可扩展性；
  - 仅测试 50/100/200 节点三种规模，网络拓扑生成方式单一（固定 20% 连边率）。
- **对比公平性问题**：集中式基线仅运行 1 个随机种子（算力约束），而其他模型为 3 个种子，统计对比的严格性不足；"比集中式低 26.3%"这一核心结论的稳健性需更多种子验证。
- **关键指标存在短板**：最大访问间隔显著高于集中式与 Grazing，说明节点忽视问题并未被完全解决，DCBF 的阈值设计（$\eta=0.1$、冻结 10 步）与 $\gamma_k$ 的取值缺乏敏感性分析。
- **理论保证缺失**：论文明确承认完全去中心化缺乏收敛保证，未给出任何收敛性或最优性分析，安全性的理论保障（DCBF 的可行性、前向不变性）也仅以启发式形式实现，未做形式化证明。

  - 算法依赖"局部子目标与全局目标一致"的问题结构，对强耦合、需全局协调的任务可能不适用；

  - 超参数（奖励权重 0.05、η=0.1、冻结步数 10、W=10）均靠人工调试确定，缺乏系统调参研究。
