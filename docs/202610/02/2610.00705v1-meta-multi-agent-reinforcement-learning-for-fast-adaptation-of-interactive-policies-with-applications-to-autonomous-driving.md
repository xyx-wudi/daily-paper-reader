## 摘要
本文提出了一种元多智能体强化学习（meta-MARL）框架，以实现多智能体系统（MAS）中交互策略的快速适应。元强化学习（meta-RL）借助双层优化机制使智能体能够快速适应新任务/新环境。然而，现有的元强化学习通常关注单智能体系统。将这些框架和算法扩展到多智能体系统会带来额外挑战，因为任务不仅由环境刻画，还由智能体之间的策略交互决定。为应对这些挑战，我们将多智能体强化学习（MARL）问题建模为马尔可夫博弈（MG），并开发了一个 meta-MARL 框架，用于在马尔可夫博弈分布上实现交互策略的快速适应。我们定义了一个称为 meta-NE 的新概念，用以描述 meta-MARL 问题中期望的解概念。我们建立了 meta-NE 与基于梯度博弈的 meta-MARL 算法驻点之间的等价性的充分条件。我们在自动驾驶任务上的评估表明，所提出的 meta-MARL 方法相比预训练的 MARL 基线实现了更快的适应，验证了该框架的有效性。

## Abstract
This paper develops a meta-multi-agent reinforcement learning (meta-MARL) framework to enable fast adaptation of interactive policies in a multi-agent system (MAS). Meta-reinforcement learning (meta-RL) enables agents to rapidly adapt to new tasks/environments using a bi-level optimization mechanism. However, existing meta-RL generally focuses on single-agent systems. Extending these frameworks and algorithms to multi-agent systems poses additional challenges, as tasks are characterized by not only the environment but also agents' strategic interactions. To address these challenges, we model multi-agent reinforcement learning (MARL) problems as Markov games (MGs) and develop a meta-MARL framework for rapid interactive policy adaptation across a distribution of MGs. A new concept, called meta-NE, is defined to describe the desired solution concept in a meta-MARL problem. Sufficient conditions for the equivalence between a meta-NE and a stationary point of the gradient-play-based meta-MARL algorithm are established. Our evaluation on autonomous-driving tasks demonstrates that the proposed meta-MARL method achieves faster adaptation than pretrained MARL baselines, validating the effectiveness of our framework.

## 2. 方法论

### 2.1 核心思想
- 将每个内层任务建模为一个 **MG**，外层则优化一个跨 MG 分布的**初始化策略**，使得对任一采样任务都能通过少量梯度步快速得到近似 NE。
- 引入 **meta-NE（元纳什均衡）** 作为 meta-MARL 的期望解概念。

### 2.2 关键定义与理论
- **meta-NE（定义 3）**：初始化策略 θ* 满足对所有智能体 i 和任意 ˜θi，都有 Ψi(θ*ᵢ, θ*₋ᵢ) ≥ Ψi(˜θi, θ*₋ᵢ)，其中 Ψi 是智能体 i 在任务分布上的期望适应后回报。
- **一阶驻点（定义 4）**：满足 (˜θi − θ*ᵢ)ᵀ∇θᵢΨi(θ*) ≤ 0。
- **假设 1（正则性）**：Xᵢ 非空、紧、凸；Ψi 连续可微。
- **假设 2（元梯度支配）**：存在常数 Cᵢ 使得 Ψi(˜θi, θ₋ᵢ) − Ψi(θ) ≤ Cᵢ · max(¯θi − θᵢ)ᵀ∇θᵢΨi(θ)。
- **定理 1**：在假设 1 和 2 下，策略为 meta-NE **当且仅当**其为诱导元博弈的一阶驻点（证明思路：凸性 + 泰勒展开 + 梯度支配不等式）。

### 2.3 面向 MPG 的 MAML 风格算法
- **命题 1**：若各智能体的适应规则相互独立（Ui,m(θi, θ₋ᵢ) = Ui,m(θi, θ′₋ᵢ)），且采样任务几乎必然为 MPG，则诱导元博弈 G 是**精确势博弈**，势函数为 Γ(θ) = E[Φm(Um(θ))]。
- **内层更新**（MPG 下梯度等价）：
  - θ′ᵢ,m = θᵢ + η₁∇θᵢΦm(θ)，堆叠后 θ′m = θ + η₁∇θΦm(θ)。
- **外层目标**：maxθ Γ(θ) = maxθ E[Φm(θ′m)] = maxθ E[Φm(θ + η₁∇θΦm(θ))]。
- **精确元梯度**：∇θΓ(θ) = E[(I + η₁∇²θΦm(θ))ᵀ ∇θ′mΦm(θ′m)]。
- **一阶 MAML 近似**：省略 Hessian 项，˜∇θΓ(θ) = E[∇θ′mΦm(θ′m)]，随后用 θ(k+1) = θ(k) + η₂˜∇θΓ(θ(k)) 更新。
- **算法 1 流程**：初始化 θ → 采样任务批次 → 对每任务采样轨迹、计算 ∇θΦm、得到 θ′m、再采样并计算 ∇θ′mΦm → 估计一阶元梯度 → 外层更新，重复 E 个 epoch。

## 3. 实验设计

### 3.1 场景与环境
- **场景**：自动驾驶**高速公路强制汇入（forced-merging）**，单车道路段，匝道车为自车，其余车辆在目标车道行驶。
- **智能体配置**：选取自车最近的 4 辆前车和 4 辆后车，加上自车构成 **9 智能体博弈（N = 9）**。
- **车辆动力学**：运动学自行车模型（kinematic bicycle model），状态为 [x, y, v, φ]，控制为纵向加速度与转向角；由于采用参考路径跟踪，动作约化为标量纵向加速度 a ∈ [−g, g]，速度约束 0–30 m/s，Δt = 0.5 s。

### 3.2 奖励与任务定义
- 奖励由四部分组成：自车速度跟踪、加速度惩罚、同车道碰撞规避、异车道冲突点到达时间差规避。
- 按照 [21] 的 MPG 充分条件设计奖励与势函数，势函数为各分量加权和。
- **任务分布 p(M)**：通过改变周围车辆（非自车）的权重参数 α(m)_i,1（表征驾驶激进程度）构造 8 维任务向量；自车权重固定。

### 3.3 策略网络与训练设置
- 确定性策略网络，全连接结构：输入层（全局观测 + one-hot 车辆索引）→ 两层 128 神经元 Leaky ReLU 隐藏层 → Tanh 输出层，输出乘以 9.81 m/s²。
- 采用**参数共享**提升训练效率。
- 训练参数：γ = 0.99，H = 60 决策步（30 s），1500 个元训练 epoch，每 epoch 采样 16 个任务，内层 1 步 SGA（η₁ = 10⁻³），外层 Adam（η₂ = 10⁻³）。
