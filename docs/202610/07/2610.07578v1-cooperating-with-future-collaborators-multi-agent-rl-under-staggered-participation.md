## 摘要
在协作式多智能体强化学习（MARL）中，智能体通常是在同时参与的条件下训练的，而在许多任务中，一些智能体会更早行动，并留下对之后参与的智能体有用的任务相关信息。我们将这一设定研究为交错参与（SP），它引入了跨时间、跨智能体的学习依赖，因为早期动作可能通过其提供的信息以及使用该信息的后续策略来影响回报。因此，在 SP 下学习既需要识别哪些信息对未来的决策有用，也需要学习后续智能体应如何使用这些信息。我们提出交错参与学习（SPL），这是一种训练时增强方法，通过面向早期智能体的前瞻性获取监督和面向后续智能体的结果监督接收者学习来处理这两个部分。我们在多种基于策略的 MARL 主干、环境和交错参与模式上评估 SPL。在 60 个 MPE/RWARE 主干设置比较中，SPL 在所有情况下都取得了更高的观测平均任务完成度，平均差异为 14.1%。这些增益还扩展到八智能体团队以及 Isaac Lab 中基于物理的 UAV-UGV 环境，为算法、时间和具身设定提供了证据。

## Abstract
In cooperative Multi-Agent Reinforcement Learning (MARL), agents are often trained under concurrent participation, while in many tasks some agents act earlier and leave task-relevant information that becomes useful to agents participating later. We study this setting as staggered participation (SP), which introduces a cross-time, cross-agent learning dependency because an early action may affect the return through the information it provides and the later policy that uses it. Learning under SP therefore requires both identifying what information is useful for future decisions and learning how later agents should use it. We propose Staggered Participation Learning (SPL), a training-time augmentation that addresses these two parts with prospective acquisition supervision for earlier agents and outcome-supervised receiver learning for later agents. We evaluate SPL across multiple policy-based MARL backbones, environments, and staggered-participation patterns. Across 60 MPE/RWARE backbone setting comparisons, SPL achieves higher observed mean task completion in every case, with an average difference of 14.1%. The gains also extend to eight-agent teams and a physics-based UAV-UGV environment in Isaac Lab, providing evidence across algorithmic, temporal, and embodied settings.

## 1. 核心问题与整体含义

- **研究动机**：合作式多智能体强化学习（MARL）通常假设所有智能体在**同一时间区间内同时参与**（concurrent participation）。但在多机器人等现实任务中，常出现"错峰参与"：一部分智能体更早开始感知/探索，另一部分智能体稍后才参与导航或执行，早期智能体留下的任务相关信息对后期智能体仍有用。
- **问题定义（Staggered Participation, SP）**：智能体在**时间上错开的参与窗口**内为同一合作目标做贡献，窗口可**部分重叠**（可短暂直接交互）或**完全分离**。论文将 agent j 称为 agent i 的"未来协作者"，若二者参与区间起始时间满足 $t_i^{start} < t_j^{start}$。
- **核心难点**：早期动作的价值是**间接且延迟**的——它通过"留下什么信息"以及"后续策略如何使用这些信息"来影响共享回报，形成**跨时间、跨智能体的学习依赖**。共享团队回报虽耦合了两者，但**不提供分离的监督信号**。
- **两个相互依赖的学习需求**：
  - **信息获取（Information Acquisition）**：早期智能体学习哪些动作能产生对未来决策有用的信息；
  - **下游利用（Downstream Utilization）**：后期智能体学习这些信息应如何影响其动作选择。
- **与已有方向的关联**：异步 MARL（动作/通信时间不同步）、动态与开放团队 MARL（成员加入/离开）、通信 MARL（学什么信息值得传递）。论文强调 SP 的独特之处在于：**信息获取与下游利用被分配到不同参与窗口、甚至不同智能体**，并被置于同一个合作学习问题中。

## 2. 方法论：Staggered Participation Learning (SPL)

### 2.1 总体思想

- SPL 是一种**训练时增强（training-time augmentation）**，在原生 MARL 目标之上为 actor 增加两个**互补的辅助监督信号**：
  - 面向早期参与者的**前瞻性获取监督（prospective acquisition supervision）**；
  - 面向未来协作者的**结果监督接收者学习（outcome-supervised receiver learning）**。
- **不修改环境奖励、不修改 critic 目标、执行时无额外通信或辅助推理**；辅助模型与目标全部仅在训练期使用。
- 形式化基础：在 Dec-POMDP 上引入参与集合 $N_t^{part}$ 与半开参与区间 $[t_i^{start}, t_i^{end})$，非参与智能体执行 null 动作且不做策略决策。

### 2.2 前瞻性获取监督（早期智能体）

- 对早期参与者的一个合法任务导向动作 $u$，用**固定的训练期任务模型**估计其证据带来的下游决策价值增量 $\Delta_i^t(u)$。
- 打分函数结合前瞻价值与获取/移动距离：
  $$s_i^t(u) = \log(\max\{\Delta_i^t(u), \epsilon_{acq}\}) - \frac{d_i^t(u)}{\tau_d}$$
  其中 $\tau_d$ 为距离温度，$\epsilon_{acq}$ 为数值稳定项。
- 确定性变换 $T_{acq}$：屏蔽非法动作、对正增益任务动作归一化、为"扫描（scan）"动作保留一小部分固定概率质量（实现中为 0.05）；若无可用的正增益动作，则扫描动作获得全部目标质量。
- 损失为对目标分布的**交叉熵蒸馏**：$L_{SPL}^{acq} = \mathbb{E}[\mathrm{CE}(q_{acq}^i, \pi_{\theta_i})]$，**仅更新早期参与者的 actor**。

### 2.3 结果监督接收者学习（后期智能体）

- **可归因结果记录**：对每个符合条件的下游决策，记录元组 $(x_j^t, u_j^t, j, y_j^t)$ 到结果回放集 $D_{out}$，$y \in \{0,1\}$ 表示成功/失败；中断、过期、无法可靠归因的尝试被排除。
- **候选共享结果模型**：$p_\psi^j(u|x) = \mathrm{sigmoid}(f_\psi(g_j(x,u)))$，用二元交叉熵从可归因结果中训练；模型**只看到被选动作的后果**，没有反事实标签。
- **证据条件化效用**：结合固定任务级成功/失败效用 $c_j^+(u)$、$c_j^-(u)$ 与目标模型 $\bar\psi$ 预测的成功概率：
  $$U_{\bar\psi}^j(u|x) = p_{\bar\psi}^j(u|x)c_j^+(u) + [1 - p_{\bar\psi}^j(u|x)]c_j^-(u)$$
  同一候选在不同证据下可得到不同效用估计。
- **接收者软偏好目标**：对当前合法动作集做标准化，再用 Boltzmann 分布构造目标 $q_{SPL}^j(u) \propto \exp(\beta z_j^t(u))$，非法动作概率为 0；$\beta$ 控制偏好强度。
- **策略监督**：$L_{SPL}^{rec} = \mathbb{E}[\mathrm{CE}(q_{SPL}^j, \pi_{\theta_j})]$，目标视为固定，**梯度不回流到结果模型、回放结果或环境动态**，仅更新后期协作者的 actor。

### 2.4 训练流程与执行

- 每次 rollout 后把可归因结果加入 $D_{out}$；满足"就绪条件"（如结果模型需 ≥128 条且每类 ≥16；接收者监督需 ≥1024 条且每类 ≥128）后更新在线结果模型，并用 EMA 更新目标模型 $\bar\psi \leftarrow (1-\rho)\bar\psi + \rho\psi$。
- SPL actor 更新与原生 actor 更新**交错**：先原生后 SPL；MAPPO 按固定顺序更新所有 actor 再更新集中 critic，IPPO 逐个智能体完成原生/SPL/局部 critic 更新，HAPPO 保持其顺序式异质 actor 更新（论文声明**不保证** SPL-HAPPO 保留原 HAPPO 的单调改进保证）。
- **执行阶段**：智能体仅按 $\pi_{\theta_i}(u|\tau, M)$ 行动，不需要获取模型、辅助目标、结果回放、结果模型或效用估计。
